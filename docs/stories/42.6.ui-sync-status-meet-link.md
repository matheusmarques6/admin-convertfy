# Story 42.6 — UI: Sync status e Meet link nas reunioes

## Story

**Como** admin user da plataforma,
**Quero** ver o status de sincronizacao Google e o link do Meet em cada reuniao,
**Para que** eu saiba se a reuniao esta no meu calendario e possa entrar rapidamente.

## Contexto

### Estado atual

- `meetings-page-client.tsx` exibe lista/calendario de reunioes sem indicacao de Google Calendar
- `Meeting` type nao inclui `google_sync_status`, `meeting_url_source`, `timezone`
- MeetingDialog (criacao/edicao) nao tem campo de timezone nem checkbox de Meet
- `meeting_url` ja existe no meeting e e exibido como link — mas sem indicacao de origem

### O que precisa mudar

1. Types atualizados com novos campos
2. Badge de sync status em cada meeting card
3. Botao "Entrar na reuniao" com Meet link
4. Checkbox "Criar Google Meet" no dialog de criacao
5. Campo timezone no dialog

## Technical Notes

### Badge component sugerido

```tsx
function GoogleSyncBadge({ status, error }: { status: string; error?: string }) {
  const config = {
    synced: { icon: CheckCircle, color: 'text-green-500', label: 'Sincronizado' },
    pending: { icon: Clock, color: 'text-yellow-500', label: 'Pendente' },
    error: { icon: AlertCircle, color: 'text-red-500', label: 'Erro de sync' },
    not_connected: { icon: CloudOff, color: 'text-muted-foreground', label: 'Nao conectado' },
  }[status] || { icon: CloudOff, color: 'text-muted-foreground', label: status }

  return (
    <Tooltip content={error || config.label}>
      <Badge variant="outline" className="gap-1">
        <config.icon className={cn('h-3 w-3', config.color)} />
        <span className="text-xs">{config.label}</span>
      </Badge>
    </Tooltip>
  )
}
```
