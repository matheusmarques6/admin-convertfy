# Story 3.4 - Board Config Presets na Criação de Membro

## Contexto
A tabela `board_config` permite configurar quais tipos de task cada membro vê no board. Atualmente os defaults são hardcoded (show_meeting_tasks + show_manual_tasks = true). O Admin precisa poder configurar isso ao criar um membro da equipe.

## Objetivo
Implementar presets de board_config por role que são aplicados automaticamente na criação do membro, com opção do Admin customizar.
