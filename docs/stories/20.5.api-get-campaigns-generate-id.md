## Story

**Como** usuario do portal que disparou uma geracao de copies,
**Quero** consultar o status atual da campanha e de cada loja,
**Para que** o frontend possa fazer polling e mostrar o progresso em tempo real.

---

## Contexto

Esta rota e usada pelo frontend para polling a cada 5s. Ela retorna o status da campanha e a lista de lojas com seus status individuais. O frontend para de fazer polling quando `generation.status !== "processing"`.

Os testes TDD cobrem: auth (3), success responses (3) = 6 testes.

---

## Acceptance Criteria

### 20.5.1 — Autenticacao e autorizacao

- [x] Usar `createClient()` para obter user autenticado via `auth.getUser()`
- [x] Lookup em `client_portal_users` com `user_id` para obter `client_id`
- [x] Retornar 401 se portal user nao encontrado
- [x] Buscar `campaign_generations` por `id` (param da URL) usando adminClient
- [x] Retornar 404 se generation nao existe
- [x] Retornar 403 se `generation.client_id !== portal_user.client_id`

### 20.5.2 — Response shape

- [x] Retornar 200 com JSON:
  ```json
  {
    "generation": {
      "id": "uuid",
      "name": "Black Friday 2026",
      "date": "2026-11-27",
      "reference_doc_url": null,
      "drive_folder_id": null,
      "drive_folder_url": null,
      "status": "processing",
      "created_at": "...",
      "updated_at": "..."
    },
    "stores": [
      {
        "id": "uuid",
        "store_id": "uuid",
        "status": "generating",
        "version": 1,
        "error_message": null,
        "generated_at": null
      }
    ]
  }
  ```
- [x] `stores` deve ser ordenada (por created_at ou store_id — consistente)

### 20.5.3 — Cenarios de resposta

- [x] Quando campanha esta "processing": retornar stores com mix de status
- [x] Quando campanha esta "done": retornar drive_folder_id e drive_folder_url
- [x] Quando store tem erro: incluir `error_message` preenchido

### 20.5.4 — Todos os testes TDD passando

- [x] Executar `npx vitest run src/app/api/campaigns/generate/[id]/route.test.ts`
- [x] Todos os 6 testes devem passar
