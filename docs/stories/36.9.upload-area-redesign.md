# Story 36.9 — Redesign Upload (Grid Assimetrico)

## Contexto

O step "Identidade Visual" tem 3 areas de upload identicas empilhadas verticalmente:
```
[  Logo da marca  ]        ← dashed border, icone, texto
[  Referencia visual  ]    ← dashed border, icone, texto
[  Manual da marca  ]      ← dashed border, icone, texto
```

Visualmente monotono — 3 retangulos iguais um embaixo do outro sem hierarquia.

## Objetivo

Criar layout assimetrico que destaca o logo (upload principal) e agrupa os opcionais.

### Layout proposto (desktop)
```
┌─────────────────────┐  ┌──────────────┐
│                     │  │  Referencia   │
│    Logo da marca    │  │   visual      │
│    (area grande)    │  ├──────────────┤
│                     │  │  Manual da    │
│                     │  │   marca       │
└─────────────────────┘  └──────────────┘
```

### Layout proposto (mobile)
```
┌─────────────────────┐
│    Logo da marca    │
└─────────────────────┘
┌─────────────────────┐
│  Referencia visual  │
└─────────────────────┘
┌─────────────────────┐
│  Manual da marca    │
└─────────────────────┘
```

## Criterios de Aceitacao

- [x] **AC 36.9.1**: Logo ocupa 60% da largura em desktop (col-span ou grid assimetrico), altura maior (~160px)
- [x] **AC 36.9.2**: Referencia visual e manual da marca em coluna de 40%, empilhados, altura menor (~70px cada)
- [x] **AC 36.9.3**: Em mobile (<640px), stack vertical com logo maior e os outros 2 compactos
- [x] **AC 36.9.4**: Subtitulo visual separando secoes: "Logo" e "Arquivos opcionais" (ou similar)
- [x] **AC 36.9.5**: Funcionalidade de upload/remove inalterada
- [x] **AC 36.9.6**: Areas de upload menores usam layout horizontal (icone a esquerda, texto ao lado) em vez de centralizado vertical

## Impacto por Disciplina

- **Dev**: 1 arquivo, ~40 linhas de diff. Reestruturar JSX/CSS do step visual_identity
- **Arquiteto**: Zero
- **DB**: Zero
- **QA**: Visual test em 375px, 768px, 1024px. Upload/remove funciona em cada posicao
