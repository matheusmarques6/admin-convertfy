## Arquitetura Tecnica

### X-Response-Time

```typescript
export async function GET(request: NextRequest) {
  const startTime = Date.now()

  // ... logica do endpoint ...

  const elapsed = Date.now() - startTime
  const response = successResponse(request, data)
  response.headers.set("X-Response-Time", `${elapsed}ms`)
  return response
}
```

**Nota:** Se `successResponse()` retorna um `NextResponse` imutavel, pode ser necessario criar o response manualmente:

```typescript
const response = NextResponse.json(data)
response.headers.set("X-Response-Time", `${elapsed}ms`)
return response
```

### Logging Padronizado

```typescript
log.info(`[Revenue] period=${period} stores=${filtered.length} time=${elapsed}ms source=cache`)
```

### Teste de Isolamento

```typescript
// Script: scripts/test-cross-tenant-isolation.ts
// Ou endpoint: /api/debug/test-isolation (protegido por CRON_SECRET)

async function testCrossTenantIsolation() {
  // 1. Buscar 2 orgs diferentes
  const { data: orgs } = await supabase
    .from('organizations')
    .select('id')
    .limit(2)

  // 2. Para cada org, buscar revenue summary
  for (const org of orgs) {
    const { data: revenue } = await supabase
      .from('store_revenue_summary')
      .select('store_id, org_id')
      .eq('org_id', org.id)

    // 3. Verificar que todos os store_ids pertencem a esta org
    for (const r of revenue) {
      const { data: store } = await supabase
        .from('client_stores')
        .select('org_id')
        .eq('id', r.store_id)
        .single()

      assert(store.org_id === org.id, `Store ${r.store_id} belongs to different org!`)
    }
  }
}
```

## Riscos e Mitigacoes

| Risco | Mitigacao |
|-------|-----------|
| X-Response-Time nao chega ao frontend (proxy/CDN strip headers) | Verificar no browser dev tools; se necessario, incluir no body da resposta |
| Logging excessivo impacta performance | Usar `info` (nao `debug`); uma linha por request |
| Teste de isolamento falha por dados de teste insuficientes | Documentar pre-requisitos (2 orgs com lojas configuradas) |
