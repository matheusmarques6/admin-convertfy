**Revisao:** @sm (River)

## Contexto

Com o `StoresListModal` criado (13.1) e a prop `allStores` chegando nos cards (13.2), esta story conecta tudo: adiciona o botao "Ver todas" no header dos cards `TopStoresCard` e `WorstPerformersCard`, e abre o modal com os dados corretos.

O botao so aparece quando ha mais de 5 lojas. Os dados sao ordenados no card antes de serem passados para o modal (descendente para "top", ascendente para "bottom").

---

## Objetivo

Adicionar botao "Ver todas" nos cards Top Lojas e Atencao Necessaria que abre o `StoresListModal` com a lista completa de lojas, ordenada corretamente e filtrada por receita > 0.

```typescript
"use client"

import { useState, useMemo } from "react"
import Link from "next/link"
import { Trophy } from "lucide-react"
import { CardContent, CardHeader, CardTitle } from "@/components/ui/card"
import { Button } from "@/components/ui/button"
import { Skeleton } from "@/components/ui/skeleton"
import { formatCurrency } from "@/lib/utils"
import { StoresListModal } from "./stores-list-modal"
import type { RevenueStoreItem } from "./total-revenue-banner"
import type { DataStatus } from "@/lib/shared/data-status"

interface TopStoresCardProps {
  stores?: RevenueStoreItem[]
  allStores?: RevenueStoreItem[]
  isLoading?: boolean
  dataStatus?: DataStatus
}

  const stores = storesProp || []

  const allStoresSorted = useMemo(() => {
    if (!allStores || allStores.length === 0) return []
    return [...allStores]
      .filter(s => (s.totalRevenueBRL ?? s.totalRevenue) > 0)
      .sort((a, b) => (b.totalRevenueBRL ?? b.totalRevenue) - (a.totalRevenueBRL ?? a.totalRevenue))
  }, [allStores])

  const showViewAll = allStoresSorted.length > 5
  const maxRevenue = stores[0]?.totalRevenueBRL ?? stores[0]?.totalRevenue ?? 1

  return (
    <div className="rounded-xl border border-border bg-card h-full">
      <CardHeader className="pb-3">
        <div className="flex items-center justify-between">
          <div className="flex items-center gap-2">
            <Trophy className="h-4 w-4 text-success" />
            <CardTitle className="text-sm font-semibold">Top Lojas</CardTitle>
          </div>
          {showViewAll && (
            <Button variant="ghost" size="sm" className="text-xs h-7 px-2" onClick={() => setModalOpen(true)}>
              Ver todas ({allStoresSorted.length})
            </Button>
          )}
        </div>
      </CardHeader>
      <CardContent className="space-y-3">
        {/* ... lista existente inalterada ... */}
      </CardContent>

      <StoresListModal
        stores={allStoresSorted}
        variant="top"
        open={modalOpen}
        onOpenChange={setModalOpen}
      />
    </div>
  )
}
```

## Riscos e Mitigacoes

| Risco | Mitigacao |
|-------|-----------|
| `allStores` undefined durante loading gera flash do botao | `showViewAll` e `false` quando `allStores` e undefined |
| Modal stale apos mudanca de periodo | `StoresListModal` tem `useEffect` que reseta pagina quando `stores` muda. Card recalcula `allStoresSorted` via `useMemo` |
| Moedas mistas (BRL + USD) no mesmo modal | Cada item exibe sua moeda nativa via `store.currency`. Sorting usa `totalRevenueBRL` (convertido) para ranking justo |
| Botao "Ver todas" muda layout do header | `Button variant="ghost" size="sm"` e discreto, `flex justify-between` ja esta no header |
| StoresListModal renderizado quando `showViewAll` e false | Dialog com `open={false}` nao renderiza conteudo (Radix Dialog behavior). Custo de memoria negligivel |
