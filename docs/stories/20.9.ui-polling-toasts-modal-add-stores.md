## Story

**Como** usuario do portal que disparou uma geracao de copies,
**Quero** ver o progresso em tempo real e poder adicionar lojas a campanhas existentes,
**Para que** eu tenha visibilidade do status e flexibilidade para expandir campanhas.

---

## Contexto

Esta story integra os comportamentos finais da feature:
1. **Polling**: a cada 5s enquanto uma campanha esta "processing", o frontend chama `GET /api/campaigns/generate/[id]` para atualizar o status
2. **Toasts**: notificacoes ao usuario quando uma campanha completa (sucesso ou com erros)
3. **Modal adicionar lojas**: permite selecionar lojas adicionais para uma campanha existente e disparar geracao

### Custom Hook (referencia)

```typescript
function useCampaignPolling(generationId: string | null) {
  const [data, setData] = useState<PollResponse | null>(null)
  const [isPolling, setIsPolling] = useState(false)

  useEffect(() => {
    if (!generationId) return
    setIsPolling(true)

    const interval = setInterval(async () => {
      const res = await fetch(`/api/campaigns/generate/${generationId}`)
      const json = await res.json()
      setData(json)

      if (json.generation.status !== "processing") {
        clearInterval(interval)
        setIsPolling(false)
      }
    }, 5000)

    return () => clearInterval(interval)
  }, [generationId])

  return { data, isPolling }
}
```
