## Story

**Como** endpoint de tracking lookup que serve widgets em storefronts de alto trafego,
**Quero** que as queries ao Supabase sejam batched com `.in()` ou joins,
**Para que** o numero de queries por request caia de ate 14 para 2-3, reduzindo latencia em 140-700ms.

---

## Contexto

### Padrao N+1 identificado em 3 paths

**Path A — Email search (linhas 226-234):**
- 1 query `tracking_orders` (ate 10 results)
- N queries `tracking_codes` (1 por order)
- Total: ate **11 queries**

**Path B — Order number search (linhas 245-254):**
- 1 query `tracking_orders` (ate 10 results)
- N queries `tracking_codes` (1 por order)
- Total: ate **11 queries**

**Path C — Tracking code search (linhas 263-276):**
- 1 query `tracking_codes` (ate 5 results)
- N queries `tracking_orders` (1 por code)
- Total: ate **6 queries**

**Path D — Sync re-read (linhas 469-481):**
- Ate 3 queries individuais por tracking code
- Total: ate **3 queries**

**Pior caso total**: 14 queries Supabase por request. Cada query adiciona 10-50ms de latencia.

---

## Acceptance Criteria

### 25.3.1 — Batch tracking_codes com `.in()` (Paths A e B)

- [ ] Apos buscar orders por email/order number, coletar todos `order.id` em um array
- [ ] Fazer UMA query com `.in("tracking_order_id", orderIds)` para buscar todos tracking codes
- [ ] Agrupar codes por `tracking_order_id` em um `Map` em memoria
- [ ] Montar resultados iterando orders e buscando codes do Map
- [ ] Queries: 2 em vez de N+1

### 25.3.2 — Batch tracking_orders com `.in()` (Path C)

- [ ] Apos buscar tracking codes, coletar todos `tracking_order_id` unicos
- [ ] Fazer UMA query com `.in("id", orderIds)` para buscar todas orders
- [ ] Montar Map de orders por id
- [ ] Queries: 2 em vez de N+1

### 25.3.3 — Batch sync re-read (Path D)

- [ ] Apos sync, buscar todos updated codes com `.in("id", staleIds)` em UMA query
- [ ] Queries: 1 em vez de ate 3

## Dev Notes

### Codigo de referencia — Path A (email)

```typescript
// ANTES (N+1):
for (const order of orders) {
  const { data: codes } = await admin
    .from("tracking_codes").select("...").eq("tracking_order_id", order.id)
  results.push({ order, tracking: codes || [] })
}

// DEPOIS (batch):
if (orders && orders.length > 0) {
  const orderIds = orders.map((o) => o.id)
  const { data: allCodes } = await admin
    .from("tracking_codes")
    .select("id, tracking_number, carrier_name, status, status_detail, last_event, tracking_events, estimated_delivery, last_checked_at, tracking_order_id")
    .in("tracking_order_id", orderIds)

  const codesByOrder = new Map<string, typeof allCodes>()
  for (const code of allCodes || []) {
    const list = codesByOrder.get(code.tracking_order_id) || []
    list.push(code)
    codesByOrder.set(code.tracking_order_id, list)
  }

  for (const order of orders) {
    results.push({ order, tracking: codesByOrder.get(order.id) || [] })
  }
}
```

### Codigo de referencia — Path C (tracking code)

```typescript
// DEPOIS (batch):
if (codes && codes.length > 0) {
  const orderIds = [...new Set(codes.map((c) => c.tracking_order_id).filter(Boolean))]
  const { data: allOrders } = await admin
    .from("tracking_orders")
    .select("id, order_name, customer_name, customer_email, order_created_at, shipped_at, delivered_at, total_price, currency, line_items, shipping_address")
    .in("id", orderIds)

  const orderMap = new Map((allOrders || []).map((o) => [o.id, o]))

  for (const code of codes) {
    const order = orderMap.get(code.tracking_order_id)
    if (order) {
      const { tracking_order_id: _, ...codeData } = code
      results.push({ order, tracking: [codeData] })
    }
  }
}
```

### Codigo de referencia — Path D (sync re-read)

```typescript
// DEPOIS (batch):
if (syncedCount > 0) {
  const { data: updatedCodes } = await admin
    .from("tracking_codes")
    .select("id, tracking_number, carrier_name, status, status_detail, last_event, tracking_events, estimated_delivery, last_checked_at")
    .in("id", staleIds)

  const updatedMap = new Map((updatedCodes || []).map((c) => [c.id, c]))

  for (const result of results) {
    for (let i = 0; i < result.tracking.length; i++) {
      const updated = updatedMap.get(result.tracking[i].id)
      if (updated) result.tracking[i] = updated
    }
  }
}
```
