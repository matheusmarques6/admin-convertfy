## Story

**Como** usuario do portal criando uma campanha,
**Quero** selecionar as lojas para as quais gerar copies usando um seletor visual,
**Para que** eu possa escolher facilmente quais lojas incluir na geracao.

---

## Contexto

O seletor de lojas e um componente reutilizavel que mostra as lojas do client como cards em grid. Permite selecao multipla, filtros por pais e idioma, e selecao/deselecao de todas. As lojas vem de `client_stores` filtradas pelo `client_id` do portal user.

Este componente e usado pelo formulario de criacao (story 20.7) e pelo modal de adicionar lojas (story 20.9).

---

## Acceptance Criteria

### 20.6.1 — Componente StoreSelector

- [x] Criar componente `StoreSelector` em `src/components/campaigns/store-selector.tsx`
- [x] Props: `stores: Store[]`, `selectedIds: string[]`, `onSelectionChange: (ids: string[]) => void`
- [x] Renderizar lojas como grid de cards (responsive: 1 col mobile, 2 col tablet, 3 col desktop)
- [x] Cada card mostra: nome da loja, pais (com bandeira emoji), idioma
- [x] Card selecionado: borda primaria + check icon
- [x] Card nao selecionado: borda neutra

### 20.6.2 — Filtros rapidos

- [x] Filter bar acima do grid com:
  - Filtro por pais (dropdown com paises unicos das lojas)
  - Filtro por idioma (dropdown com idiomas unicos das lojas)
  - Botao "Selecionar todas" / "Deselecionar todas"
- [x] Filtros sao client-side (nao fazem API call)
- [x] Filtros podem ser combinados (pais E idioma)

### 20.6.3 — Estado de selecao

- [x] Clicar em card toggle a selecao (add/remove do array selectedIds)
- [x] Contador de lojas selecionadas visivel: "X de Y lojas selecionadas"
- [x] Se nenhuma loja selecionada, mostrar hint visual

### 20.6.4 — Acessibilidade e UX

- [x] Cards devem ser keyboard-navigable (Tab + Enter/Space)
- [x] Aria labels nos cards e filtros
- [x] Loading state (skeleton) enquanto lojas carregam
