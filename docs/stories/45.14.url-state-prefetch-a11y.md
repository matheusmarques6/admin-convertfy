# Story 45.14 — URL State for Filters + Prefetch Adjacent Months

## Status: Ready for Dev (depends on 45.8)
## Effort: LOW-MEDIUM (1-2h)
## Priority: LOW

## Context

Two polish items:

### 1. URL State for Filters

Currently, filters (month, year, store, channel, status) are ephemeral useState. Refreshing the page or sharing a link loses filter context. Use `nuqs` (type-safe URL search params for Next.js App Router) to persist filters in the URL.

### 2. Prefetch Adjacent Months

When viewing March, prefetch February and April campaign data so month navigation feels instant. SWR already supports `preload()`.

**Note**: Accessibility (a11y) was moved to Story 45.15 — it's an independent concern with higher effort.
