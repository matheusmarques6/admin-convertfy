## Story

**Como** usuario acessando paginas de onboarding ou configuracao de loja,
**Quero** que URLs geradas dinamicamente nao causem hydration mismatch,
**Para que** a pagina carregue sem erros no console.

---

## Contexto

Varios componentes usam `typeof window !== "undefined" ? window.location.origin : ""` diretamente no render path (em `<Input value={...}>` ou `useMemo`). No servidor, o valor e `""` (ou um fallback hardcoded). No cliente, e `"https://admin.convertfy.com.br"`. Isso causa mismatch textual direto.

### Arquivos afetados

| Arquivo | Linha | Fallback SSR |
|---------|-------|-------------|
| `src/components/onboarding/onboarding-tabs.tsx` | 335 | `""` (vazio) |
| `src/components/stores/store-form-tab.tsx` | 57 | `""` (vazio) |
| `src/components/stores/store-tracking-tab.tsx` | 159, 175 | `"https://app.convertfy.com.br"` |
| `src/app/portal/tracking/page.tsx` | 251 | `"https://admin.convertfy.com.br"` |
| `src/app/portal/tracking/script/page.tsx` | 116 | `"https://admin.convertfy.com.br"` |

Os com fallback `""` sao os mais problematicos (mismatch garantido).
