- [ ] Total estimado: ~75 linhas removidas

### 25.5.2 — Unificar `detectCarrier` duplicado

- [ ] `detectCarrier()` em `tracking.service.ts` (linhas ~196-247) duplica `detectCarrierProvider()` de `carriers.ts`
- [ ] Refatorar `trackVia17track()` para usar `detectCarrierProvider()` + mapeamento para codigo 17track
- [ ] Remover `detectCarrier()` e `CARRIER_CODES` map de `tracking.service.ts`
- [ ] Manter `CARRIER_NAMES` (usado para resolver nomes de carrier na resposta 17track)

### 25.5.3 — Guard para attachShadow em SPA

- [ ] Em `widget.js/route.ts`, envolver `attachShadow()` em try-catch:
  ```javascript
  var shadow;
  try {
    shadow = host.shadowRoot || host.attachShadow({ mode: 'open' });
  } catch(e) {
    // Fallback: recriar host element
    var newHost = document.createElement('div');
    newHost.id = host.id;
    host.parentNode.replaceChild(newHost, host);
    host = newHost;
    shadow = host.attachShadow({ mode: 'open' });
  }
  ```
- [ ] Alternativa simples: se `mode: 'closed'`, mudar para `mode: 'open'` para poder checar `host.shadowRoot`
