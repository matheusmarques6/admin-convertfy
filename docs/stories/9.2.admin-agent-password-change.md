# Story 9.2 - Admin/Agent Password Change

**Prioridade:** P0
**Sprint:** Current
**Assignee:** @dev
**Revisao:** @sm (River)
**Status:** Pending
**Epic:** 9 - Configuracoes de Conta e Perfil
**Fase:** 1 - Core Account Settings

---

## Contexto

Atualmente nao existe funcionalidade para admin/agent alterar sua propria senha. O endpoint `/api/auth/change-password` existe mas eh de uso exclusivo para first-login (quando `must_change_password` eh true). O portal do cliente possui um endpoint funcional em `/api/portal/settings/password/route.ts` que pode servir como referencia.

Existe uma inconsistencia no minimo de caracteres para senhas: o endpoint `/api/auth/change-password` usa 6 caracteres enquanto o padrao de seguranca do projeto define 8 caracteres.

---

## Objetivo

1. Criar servico compartilhado `changePassword()` para reutilizacao entre admin e portal
2. Criar endpoint de alteracao de senha para admin/agent com verificacao de senha atual
3. Adicionar secao de alteracao de senha na pagina de perfil
4. Refatorar endpoint do portal para usar o servico compartilhado
5. Padronizar minimo de 8 caracteres em todos os endpoints de senha

## Arquitetura Tecnica

### Servico Compartilhado

```typescript
// src/lib/services/auth.service.ts
import { SupabaseClient } from "@supabase/supabase-js";

interface ChangePasswordResult {
  success: boolean;
  error?: string;
}

export async function changePassword(
  supabase: SupabaseClient,
  email: string,
  currentPassword: string,
  newPassword: string
): Promise<ChangePasswordResult> {
  // 1. Verificar senha atual
  const { error: signInError } = await supabase.auth.signInWithPassword({
    email,
    password: currentPassword,
  });

  if (signInError) {
    return { success: false, error: "Senha atual incorreta" };
  }

  // 2. Atualizar para nova senha
  const { error: updateError } = await supabase.auth.updateUser({
    password: newPassword,
  });

  if (updateError) {
    return { success: false, error: "Erro ao atualizar senha" };
  }

  return { success: true };
}
```

### Endpoint PUT /api/settings/password

```typescript
// src/app/api/settings/password/route.ts
import { z } from "zod";
import { createClient } from "@/lib/supabase/server";
import { changePassword } from "@/lib/services/auth.service";

const passwordChangeSchema = z.object({
  currentPassword: z.string().min(1, "Senha atual obrigatoria"),
  newPassword: z.string().min(8, "Nova senha deve ter pelo menos 8 caracteres"),
  confirmPassword: z.string(),
}).refine((data) => data.newPassword === data.confirmPassword, {
  message: "Senhas nao conferem",
  path: ["confirmPassword"],
});

export async function PUT(request: Request) {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();

  if (!user?.email) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const body = await request.json();
  const parsed = passwordChangeSchema.safeParse(body);

  if (!parsed.success) {
    return NextResponse.json(
      { error: "Validation failed", details: parsed.error.flatten() },
      { status: 400 }
    );
  }

  const result = await changePassword(
    supabase,
    user.email,
    parsed.data.currentPassword,
    parsed.data.newPassword
  );

  if (!result.success) {
    return NextResponse.json({ error: result.error }, { status: 403 });
  }

  return NextResponse.json({ success: true });
}
```

## Riscos e Mitigacoes

| Risco | Mitigacao |

| Brute force na verificacao de senha atual | Rate limiting obrigatorio no endpoint |
