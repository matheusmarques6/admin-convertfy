## Contexto

Com os dados de revenue vindo de cache pre-computado (store_revenue_summary), o usuario precisa de transparencia sobre a atualidade e confiabilidade dos dados. Duas informacoes sao criticas:

1. **fetched_at**: Quando os dados foram atualizados pela ultima vez. Permite ao usuario saber se esta vendo dados de 5 minutos atras ou 2 horas atras.

2. **sync_status**: Se alguma loja teve erro ou sync parcial, o usuario deve ser informado visualmente para evitar tomar decisoes baseadas em dados incompletos.

---

## Objetivo

1. Mostrar "Dados atualizados ha X minutos" no dashboard e na pagina de lojas
2. Mostrar indicador visual quando `sync_status = 'partial'` ou `'error'`

### Componente de "Atualizado ha X"

```typescript
function TimeAgo({ date }: { date: string }) {
  const minutes = Math.floor((Date.now() - new Date(date).getTime()) / 60000)

  if (minutes < 1) return <span>Atualizado agora</span>
  if (minutes < 60) return <span>Atualizado ha {minutes} min</span>
  const hours = Math.floor(minutes / 60)
  return <span>Atualizado ha {hours}h</span>
}
```

### Badge de Sync Status

```tsx
import { AlertTriangle, Clock, CheckCircle } from "lucide-react"
import { Badge } from "@/components/ui/badge"
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@/components/ui/tooltip"

function SyncStatusBadge({ status }: { status: string }) {
  if (status === 'ok') return null // Nao mostrar nada quando tudo OK

  if (status === 'pending') {
    return (
      <TooltipProvider>
        <Tooltip>
          <TooltipTrigger>
            <Badge variant="outline" className="text-muted-foreground">
              <Clock className="w-3 h-3 mr-1" />
              Aguardando
            </Badge>
          </TooltipTrigger>
          <TooltipContent>Aguardando primeira sincronizacao</TooltipContent>
        </Tooltip>
      </TooltipProvider>
    )
  }

  if (status === 'partial') {
    return (
      <TooltipProvider>
        <Tooltip>
          <TooltipTrigger>
            <Badge variant="outline" className="text-yellow-600 dark:text-yellow-400">
              <AlertTriangle className="w-3 h-3 mr-1" />
              Parcial
            </Badge>
          </TooltipTrigger>
          <TooltipContent>Sincronizacao parcial. Alguns dados podem estar incompletos.</TooltipContent>
        </Tooltip>
      </TooltipProvider>
    )
  }

  // error
  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger>
          <Badge variant="outline" className="text-red-600 dark:text-red-400">
            <AlertTriangle className="w-3 h-3 mr-1" />
            Erro
          </Badge>
        </TooltipTrigger>
        <TooltipContent>Erro na sincronizacao. Revenue pode estar desatualizado.</TooltipContent>
      </Tooltip>
    </TooltipProvider>
  )
}
```

## Riscos e Mitigacoes

| Risco | Mitigacao |
|-------|-----------|
| "Atualizado ha 3 horas" causa desconfianca | Normal se cron falhar; badge de erro explica a situacao |
| Muitos badges poluem a UI | Mostrar badge apenas para partial/error/pending; ok = nada |
| TimeAgo fica desatualizado (mostra "ha 5 min" por 10 min) | Componente client-side pode usar setInterval de 1min; ou aceitar staleness do SWR refresh |
