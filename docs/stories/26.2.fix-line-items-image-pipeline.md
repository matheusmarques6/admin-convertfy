## Story

**Como** sistema de tracking que exibe dados de pedidos ao consumidor final,
**Quero** que o pipeline de dados preserve `image_url` e todos os campos de `line_items`,
**Para que** o widget possa exibir imagens e detalhes dos produtos comprados.

---

## Contexto

### Pipeline Atual (4 pontos de quebra)

```
Shopify Order
    |
    v
Webhook (tracking_orders) --- image_url: SIM (item.image?.src)
    |
Cron Sync (order_tracking_cache) --- image_url: NAO (omitido)
    |
OrderLookupService --- image_url: NAO (omitido)
    |
mapLookupResults (lookup route) --- line_items: hardcoded []
    |
Widget --- NAO renderiza line_items
```

### Dados da Shopify disponiveis em `order.line_items[]`

```typescript
{
  title: string          // "Camiseta Premium"
  quantity: number       // 2
  price: string          // "79.90"
  image?: { src: string } // "https://cdn.shopify.com/..."
  product_id: number
  variant_id: number
  sku: string
}
```

### Impacto

- Pedidos via webhook: tem imagem em `tracking_orders` (OK)
- Pedidos via cron sync: perdem imagem em `order_tracking_cache` (BUG)
- Pedidos via OrderLookupService (email lookup Shopify): perdem imagem (BUG)
- Resultado de `mapLookupResults`: sempre retorna `line_items: []` (BUG)
