## Story

**Como** consumidor brasileiro rastreando meu pedido,
**Quero** que todos os eventos de tracking aparecam em portugues,
**Para que** eu entenda o status da minha entrega sem precisar saber ingles.

---

## Contexto

### Sistema atual de traducao

```
src/lib/tracking/translate-events.ts (engine)
    |
    v
Camada 1: Exact match (dicionario pt-BR.ts, ~220 frases)
    |
Camada 2: Regex patterns (ex: "arrived at {X} facility" -> "Chegou a unidade de {X}")
    |
Camada 3: Partial/longest match
    |
Camada 4: [NAO EXISTE] Fallback → retorna texto original em ingles
```

### Problema

Eventos de 17track, TrackingMore e Cainiao que nao constam no dicionario chegam em ingles ao widget. Exemplos reais de frases nao traduzidas:

- "The item has been processed through a facility in ISC NEW YORK NY"
- "Shipment information received"
- "Customs clearance processing"
- "Item dispatched to destination country"
- "Available for pickup at post office"

### Solucao proposta (Arquiteto)

Adicionar Camada 4: **fallback word-level** que substitui termos-chave por equivalentes em PT. Resultado e um "portingles" compreensivel — melhor que ingles puro para consumidor brasileiro.

## Dev Notes

### Exemplo de fallback word-level

```typescript
// Input: "The item has been processed through a facility in ISC NEW YORK"
// Camadas 1-3: sem match
// Camada 4 (word-level):
//   "item" → "pacote"
//   "processed" → "processado"
//   "facility" → "unidade"
// Output: "The pacote has been processado through a unidade in ISC NEW YORK"
```

Resultado imperfeito mas MUITO mais util que ingles puro para consumidor brasileiro.

### Estrutura sugerida do fallback dict

```typescript
const WORD_FALLBACK_PT: Record<string, string> = {
  "arrived": "chegou",
  "arrive": "chegou",
  "departed": "partiu",
  "depart": "partiu",
  "delivered": "entregue",
  "delivery": "entrega",
  // ... ~40 termos
}

// IMPORTANTE (QA): Pre-compilar regexes no module level para evitar
// ~40 compilacoes por chamada. Exemplo:
const WORD_FALLBACK_COMPILED = Object.entries(WORD_FALLBACK_PT).map(
  ([en, pt]) => ({ regex: new RegExp(`\\b${en}\\b`, "gi"), replacement: pt })
)

function translateFallbackWords(text: string, lang: string): string {
  if (lang !== "pt-BR" && lang !== "pt") return text

  let result = text
  let changed = false
  for (const { regex, replacement } of WORD_FALLBACK_COMPILED) {
    regex.lastIndex = 0 // reset stateful regex
    if (regex.test(result)) {
      regex.lastIndex = 0
      result = result.replace(regex, replacement)
      changed = true
    }
  }
  return changed ? result : text
}
```
