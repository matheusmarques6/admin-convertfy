# Story 23.1 -- Componente CurrencyInput + Correcao nos Formularios Financeiros

## Status
In Progress

## Story

**Como** usuario do admin,
**Quero** digitar valores monetarios no formato brasileiro (6.000,00 = seis mil reais),
**Para que** cobranças, assinaturas e contratos sejam criados com o valor correto.

---

## Dependencia

> Nenhuma. Esta story pode ser implementada independentemente.
> Story 23.2 (validacao server-side) deve ser feita APOS esta.

## Contexto

Todos os inputs monetarios usam `<input type="number">` que interpreta `.` como separador decimal (padrao americano). Quando o usuario digita `6.000` pensando em "seis mil reais", `parseFloat("6.000")` retorna `6.0`, gerando cobranca de R$ 6,00.

### Abordagem

Criar componente `CurrencyInput` custom que:
- Usa `type="text"` + `inputMode="decimal"` (teclado numerico no mobile, compativel iOS)
- Armazena valor em **centavos** (integer) internamente
- Formata para `6.000,00` no display via `Intl.NumberFormat("pt-BR")`
- Expoe `onValueChange(cents: number)` como callback
- No submit: `centsToReais(cents)` = valor em reais para API/banco
- Preview integrado no componente (prop `showPreview`)
- Prefixo `R$` integrado no componente

### Dados atuais (auditoria DB)

- `client_charges`: 0 registros (vazia)
- `client_subscriptions`: 2 registros com valor 6000.00 (corretos)
- `contracts`: 0 registros (vazia)
- **Nenhum dado corrompido.** Nao precisa de migracao de dados.

## Dev Notes

### Logica do CurrencyInput (centavos)

A ideia e simples: o usuario digita apenas numeros. Cada numero digitado desloca os centavos.

```
Digita 6      -> 6 centavos     -> exibe "0,06"
Digita 0      -> 60 centavos    -> exibe "0,60"
Digita 0      -> 600 centavos   -> exibe "6,00"
Digita 0      -> 6000 centavos  -> exibe "60,00"
Digita 0      -> 60000 centavos -> exibe "600,00"
Digita 0      -> 600000 centavos-> exibe "6.000,00"
```

Apagar (Backspace): `Math.floor(cents / 10)`

### Edge case de paste

Colar textos extrai apenas digitos. Isso significa:
- Colar `"R$ 6.000,00"` -> digitos `"600000"` -> 600000 centavos = R$ 6.000,00 (correto)
- Colar `"6000"` -> digitos `"6000"` -> 6000 centavos = R$ 60,00 (pode nao ser o esperado)
- O **preview** mitiga isso: usuario ve o valor formatado antes de submeter

### Conversao para API

```typescript
import { centsToReais } from "@/lib/currency"
// No submit handler
const valueInReais = centsToReais(chargeForm.value)
// Ex: 600000 centavos -> 6000.00 reais
```

### Calculo de parcelas

```typescript
// Usar centsToReais para converter, formatCurrency para exibir
formatCurrency(centsToReais(chargeForm.value) / n)
// Ex: centsToReais(600000) / 12 = 6000.00 / 12 = 500.00
```
