## Story

**Como** usuario do portal,
**Quero** preencher um formulario com nome da campanha, data, documento de referencia e lojas,
**Para que** eu possa iniciar a geracao de copies para as lojas selecionadas.

---

## Contexto

O formulario e a pagina principal de `/portal/campaigns/gerar`. Ele integra o `StoreSelector` (story 20.6) e chama `POST /api/campaigns/generate` (story 20.3). Apos submit com sucesso, redireciona para a tela de historico ou mostra toast com link para acompanhar.

---

## Acceptance Criteria

### 20.7.1 — Pagina /portal/campaigns/gerar

- [x] Criar pagina em `src/app/portal/campaigns/gerar/page.tsx`
- [x] Layout: formulario com campos empilhados verticalmente
- [x] Titulo: "Gerar Copies de Campanha"
- [x] Adicionar entrada "Gerar Copies" na navegacao do portal (sidebar ou tabs de campanhas)
- [x] Garantir que rota esta acessivel via navegacao existente do portal

### 20.7.2 — Campos do formulario

- [x] Campo `Nome da Campanha` (input text, obrigatorio, max 255 chars)
- [x] Campo `Data da Campanha` (date picker, formato YYYY-MM-DD, obrigatorio)
- [x] Campo `Documento de Referencia` (input URL, opcional — placeholder com exemplo)
- [x] Componente `StoreSelector` integrado (story 20.6)
- [x] Validacao client-side com zod (reutilizar `generateRequestSchema` da story 20.1)

### 20.7.3 — Fetch de lojas do client

- [x] No mount da pagina, buscar lojas do client via API ou Supabase client
- [x] Passar lojas como props para o `StoreSelector`
- [x] Mostrar skeleton/loading enquanto carrega

### 20.7.4 — Submit do formulario

- [x] Botao "Gerar Copies" (desabilitado se form invalido ou nenhuma loja selecionada)
- [x] Ao clicar, chamar `POST /api/campaigns/generate` com body validado
- [x] Loading state no botao durante a request
- [x] Em caso de sucesso: toast "Geracao iniciada!" + redirecionar para historico ou polling view
- [x] Em caso de erro: toast com mensagem de erro

### 20.7.5 — Error handling

- [x] Mostrar erros de validacao inline nos campos
- [x] Se API retorna 400/401/403: mostrar toast com mensagem descritiva
- [x] Se API retorna 500: toast generico "Erro ao iniciar geracao. Tente novamente."
