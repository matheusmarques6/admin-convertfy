# Story 36.12 — Step Instrucional "Criar App Shopify" com Seletor de Permissoes

## Contexto

Clientes Shopify precisam criar um app personalizado no admin da loja para integrar com a Convertfy. Hoje nao ha nenhuma orientacao no onboarding sobre isso. O step deve ensinar passo a passo E gerar o texto de permissoes pronto para colar.

## Objetivo

Adicionar step condicional (Shopify only) que:
1. Ensina detalhadamente como criar um custom app no admin Shopify
2. Oferece seletor interativo de permissoes (checkboxes) com opcao "Selecionar todas"
3. Gera texto pronto para copiar com as permissoes selecionadas
4. Aparece ANTES do step "Codigo Colaborador" em ambos os forms

## Seletor de Permissoes — Conceito

O Shopify exige que o lojista selecione scopes manualmente no admin. Em vez de listar nomes tecnicos, o form mostra checkboxes com descricoes amigaveis + botao "Selecionar todas (recomendado)":

```
[x] Selecionar todas (recomendado)
────────────────────────────────────
[x] Produtos — read_products
[x] Pedidos — read_orders
[x] Clientes — read_customers
[x] Inventario — read_inventory
[x] Analytics — read_analytics
```

> **IMPORTANTE**: Estes sao os 5 scopes que a Convertfy utiliza atualmente (identicos ao OAuth flow em `src/app/api/integrations/shopify/authorize/route.ts`). NAO pedir scopes que a plataforma nao usa — principio de minimo privilegio.

Ao selecionar, gera texto pronto num bloco copiavel:

```
Permissoes necessarias para o app Convertfy:
read_products, read_orders, read_customers, read_inventory, read_analytics
```

Com botao "Copiar" que copia para o clipboard.

## Tutorial Detalhado — Conteudo do Step

O tutorial deve ser EXTREMAMENTE detalhado, passo a passo:

### Passo 1 — Acessar o Admin
- Abra o admin da sua loja Shopify
- URL: `suaLoja.myshopify.com/admin`
- [Placeholder para screenshot: tela de login do admin]

### Passo 2 — Ir para Apps
- No menu lateral, clique em **Configuracoes** (icone de engrenagem)
- Depois clique em **Apps e canais de vendas**
- No canto superior, clique em **Desenvolver apps**
- [Placeholder para screenshot: menu configuracoes > apps]

### Passo 3 — Permitir desenvolvimento
- Se for a primeira vez, clique em **Permitir desenvolvimento de apps personalizados**
- Confirme clicando em **Permitir desenvolvimento de apps personalizados** novamente
- [Placeholder para screenshot: botao de permitir]

### Passo 4 — Criar o App
- Clique em **Criar um app**
- No campo "Nome do app", digite: **convertfy**
- Clique em **Criar app**
- [Placeholder para screenshot: modal de criar app]

### Passo 5 — Configurar Permissoes
- Na aba **Configuracao**, clique em **Configurar escopos da API Admin**
- Selecione as permissoes listadas abaixo (use o seletor para gerar a lista)
- [Aqui entra o SELETOR INTERATIVO de permissoes com checkboxes]
- [Bloco copiavel com o texto gerado]
- Clique em **Salvar**
- [Placeholder para screenshot: tela de escopos]

### Passo 6 — Instalar o App
- Volte para a aba **Visao geral**
- Clique em **Instalar app**
- Confirme clicando em **Instalar**
- [Placeholder para screenshot: botao instalar]

### Passo 7 — Copiar o Token
- Apos instalar, a tela mostrara o **Admin API access token**
- **ATENCAO**: Este token aparece apenas UMA VEZ. Copie agora!
- [Callout amber com aviso]
- Cole o token no campo abaixo (ou guarde para configurar depois)
