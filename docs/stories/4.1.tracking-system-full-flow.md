# Story 4.1 - Sistema de Rastreio: Script Embeddable → 17Track → Shopify → Klaviyo → DB Local

## Contexto

O sistema de rastreio é uma funcionalidade **customer-facing** que permite ao cliente final de uma loja rastrear seus pedidos diretamente no site da loja, através de um script embeddable fornecido pela Convertfy.

O fluxo possui **dois caminhos de entrada**:

1. **Por código de rastreio**: Cliente digita o tracking code → busca direto na 17Track API → exibe status tratado
2. **Por email**: Cliente digita email → busca pedido na Shopify → extrai tracking code → busca na 17Track → exibe status tratado. Se não encontrar na Shopify, tenta Klaviyo. Se não encontrar na Klaviyo, tenta no banco local (cache de 30 dias).

Atualmente **nenhuma parte deste sistema existe**. Precisa ser construído do zero, aproveitando a infraestrutura existente (ShopifyService, KlaviyoService, credentials.service, Supabase).

## Objetivo

Implementar o sistema completo de rastreio de pedidos com script embeddable, integração com 17Track API, fallback chain (Shopify → Klaviyo → DB local), e cache de pedidos de 30 dias.

### Fase 1 — Banco de Dados e Cache de Pedidos

- [x] **4.1.1** Criar migration `20260227_01_tracking_system.sql` com as tabelas:
  ```sql
  -- Cache de pedidos para lookup por email (retenção 30 dias)
  CREATE TABLE order_tracking_cache (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    org_id UUID NOT NULL REFERENCES organizations(id),
    store_id UUID NOT NULL REFERENCES client_stores(id),

    -- Dados do pedido
    order_id TEXT NOT NULL,              -- ID do pedido na Shopify
    order_number TEXT NOT NULL,          -- "#1001"
    customer_email TEXT NOT NULL,
    customer_name TEXT,

    -- Dados de rastreio
    tracking_code TEXT,                  -- Código de rastreio
    tracking_carrier TEXT,               -- Transportadora
    fulfillment_status TEXT,             -- Status do fulfillment Shopify

    -- Itens (resumo)
    line_items JSONB DEFAULT '[]',       -- [{title, quantity, price, image_url}]
    total_price NUMERIC(10,2),
    currency TEXT DEFAULT 'BRL',

    -- Datas
    order_created_at TIMESTAMPTZ,
    shipped_at TIMESTAMPTZ,

    -- Meta
    source TEXT NOT NULL DEFAULT 'shopify'
      CHECK (source IN ('shopify', 'klaviyo', 'manual')),
    expires_at TIMESTAMPTZ NOT NULL DEFAULT (now() + INTERVAL '30 days'),
    created_at TIMESTAMPTZ DEFAULT now(),
    updated_at TIMESTAMPTZ DEFAULT now(),

    UNIQUE(store_id, order_id)
  );

  CREATE INDEX idx_otc_email ON order_tracking_cache(customer_email, store_id);
  CREATE INDEX idx_otc_tracking ON order_tracking_cache(tracking_code, store_id);
  CREATE INDEX idx_otc_expires ON order_tracking_cache(expires_at);

  -- Configuração de rastreio por loja
  CREATE TABLE tracking_config (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    org_id UUID NOT NULL REFERENCES organizations(id),
    store_id UUID NOT NULL REFERENCES client_stores(id),

    -- 17Track API
    seventeen_track_api_key TEXT,        -- Encrypted com enc:v1:

    -- Customização do widget
    widget_config JSONB DEFAULT '{
      "primary_color": "#000000",
      "logo_url": null,
      "custom_css": null,
      "show_carrier_logo": true,
      "language": "pt-BR",
      "placeholder_tracking": "Digite seu código de rastreio",
      "placeholder_email": "Digite seu email"
    }',

    -- Controle
    enabled BOOLEAN DEFAULT false,
    created_at TIMESTAMPTZ DEFAULT now(),
    updated_at TIMESTAMPTZ DEFAULT now(),

    UNIQUE(store_id)
  );
  ```

  ```typescript
  interface OrderLookupResult {
    found: boolean
    source: 'shopify' | 'klaviyo' | 'cache'
    order: {
      order_number: string
      customer_name: string
      tracking_code: string | null
      carrier: string | null
      items: Array<{ title: string; quantity: number; price: string; image_url?: string }>
      total_price: string
      currency: string
      order_date: string
      fulfillment_status: string
    } | null
  }

  class OrderLookupService {
    // Busca encadeada: Shopify → Klaviyo → Cache local
    async findByEmail(
      storeId: string,
      email: string
    ): Promise<OrderLookupResult[]>

      storeId: string,
      trackingCode: string
    ): Promise<OrderLookupResult | null>
  }
  ```
