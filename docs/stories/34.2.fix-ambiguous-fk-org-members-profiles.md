# Story 34.2 — Fix Ambiguous FK org_members→profiles

## Story

**Como** usuario do dashboard que acessa CampaignTasks e Meetings,
**Quero** que as queries funcionem sem erro de FK ambigua,
**Para que** eu possa ver tarefas de campanha e reunioes corretamente.

## Contexto

### Problema observado em producao

A tabela `org_members` tem 2 foreign keys para `profiles`:
- `profile_id` → profiles(id) — o membro em si
- `invited_by` → profiles(id) — quem convidou

Quando uma query PostgREST faz `profile:profiles(...)` sem especificar qual FK, o PostgREST retorna erro **PGRST201** (ambiguous relationship).

### Ocorrencias identificadas

**8 ocorrencias em 5 arquivos** (4 originais + 4 adicionais encontradas pelo QA):

1. **`src/app/api/campaigns/tasks/route.ts:44`** — query em `campaign_generation_tasks`
```typescript
assignee:org_members!assignee_id(
  id, profile_id,
  profile:profiles(name, avatar_url)  // BUG: FK ambigua
)
```

2. **`src/app/api/meetings/route.ts:130`** — GET meetings, resolucao de participantes
```typescript
.from("org_members").select("id, profile:profiles(id, name, email, avatar_url)")  // BUG
```

3. **`src/app/api/meetings/route.ts:268`** — POST meetings, resolucao de participantes
```typescript
.from("org_members").select("id, profile:profiles(id, name, email, avatar_url)")  // BUG
```

4. **`src/app/api/meetings/[id]/route.ts:92`** — GET meeting by ID
```typescript
.from("org_members").select("id, profile:profiles(id, name, email, avatar_url)")  // BUG
```

5. **`src/app/api/meetings/[id]/route.ts:274`** — PUT meeting by ID
```typescript
.from("org_members").select("id, profile:profiles(id, name, email, avatar_url)")  // BUG
```

6. **`src/app/(dashboard)/board/page.tsx:270`** — Board page, resolucao de participantes de meetings
```typescript
.from("org_members").select("id, profile:profiles(id, name, email, avatar_url)")  // BUG
```

7. **`src/app/(dashboard)/meetings/page.tsx:78`** — Meetings page, resolucao de participantes *(encontrada pelo QA)*
```typescript
.from("org_members").select("id, profile:profiles(id, name, email, avatar_url)")  // BUG
```

8. **`src/app/(dashboard)/meetings/page.tsx:114`** — Meetings page, org members para selector de participantes *(encontrada pelo QA, 2a revisao)*
```typescript
.from("org_members").select("id, role, profile:profiles(id, name, email, avatar_url)")  // BUG
```

### Fix

Adicionar `!org_members_profile_id_fkey` apos `profiles` em todas as ocorrencias:

```typescript
// ANTES (bug):
profile:profiles(id, name, email, avatar_url)

// DEPOIS (fix):
profile:profiles!org_members_profile_id_fkey(id, name, email, avatar_url)
```

**Nota:** O BoardPage linha 93 JA tem o fix correto no select principal da tasks query:
```typescript
profile:profiles!org_members_profile_id_fkey(id, name, email, avatar_url)
```
Porem a linha 270 (resolucao de meetings participantes) NAO tem.
