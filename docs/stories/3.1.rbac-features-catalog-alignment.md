# Story 3.1 - Alinhar Features Catalog com Roles Reais

## Contexto
O sistema atual tem 8 roles no enum `org_role` e 14 features no `features_catalog`. Os defaults automáticos (trigger on insert) só configuram corretamente `owner` e `manager`. Os roles `designer` e `developer` recebem apenas `calendar_control` + `request_execute`, o que não reflete o uso real.

## Objetivo
Realinhar o mapeamento role→features para os 4 perfis principais: Admin (owner), COO (manager), Design (designer), Implementação (developer).
