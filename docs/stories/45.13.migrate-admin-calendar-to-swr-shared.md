# Story 45.13 — Migrate Admin Calendar to SWR + Adopt Shared Components

## Status: Ready for Dev (depends on 45.7, 45.8)
## Effort: MEDIUM (3-4h)
## Priority: LOW

## Context

The admin calendar uses a manual `useEffect` + `fetch` pattern without cache, deduplication, retry, or `keepPreviousData`. After Stories 45.7-45.8 create shared calendar components, the admin calendar should adopt them for consistency.

## Current Admin Files

- `src/app/admin/campaigns/page.tsx` — 373 lines
- `src/app/admin/campaigns/use-campaigns-calendar.ts` — manual fetch hook
- `src/app/admin/campaigns/calendar-grid.tsx` — admin-specific grid component

## Deliverables

1. **Migrate hook to SWR** — Replace `useEffect` + `fetch` with `useSWR`, adding `keepPreviousData`, `dedupingInterval`, and `errorRetryCount`
2. **Adopt shared CalendarGrid** — Replace local `calendar-grid.tsx` with import from `src/components/calendar/`
3. **Adopt shared constants** — Import CHANNEL_CONFIG, STATUS_CONFIG from shared module
4. **Deprecate local files** — Mark admin `calendar-grid.tsx` as deprecated or delete and re-export

## Acceptance Criteria

- [ ] **AC 45.13.1** Admin hook uses SWR instead of `useEffect` + `fetch`
- [ ] **AC 45.13.2** Admin page uses shared `CalendarGrid` component
- [ ] **AC 45.13.3** Admin page uses shared `CHANNEL_CONFIG` and `STATUS_CONFIG`
- [ ] **AC 45.13.4** Old admin `calendar-grid.tsx` removed or re-exports shared version
- [ ] **AC 45.13.5** Admin calendar has `keepPreviousData` behavior (no flash on month change)
- [ ] **AC 45.13.6** No behavioral changes — same visual output for admin users
- [ ] **AC 45.13.7** Lint + typecheck pass
