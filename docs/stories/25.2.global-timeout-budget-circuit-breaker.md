## Story

**Como** sistema de tracking que roda em Vercel serverless (timeout 60s),
**Quero** que a cadeia de providers tenha um budget de tempo global com abort cascading,
**Para que** o pior caso nunca exceda 25s (providers) + 15s (sync) = 40s, com margem segura para o limite de 60s.

---

## Contexto

### Problema: Timeout Cascade

O `trackWithBestProvider()` executa providers sequencialmente, cada um com timeout individual de 8s:

| Provider | Timeout | Cenario falha |
|----------|---------|---------------|
| Correios | 8s | 403 (cloud IP blocked) |
| PostNL | 8s | Timeout se carrier match |
| Cainiao | 8s | 302 redirect |
| TrackingMore | 8s | 412 format error |
| 17track register | 8s | Timeout |
| 17track sleep | 2s | Hardcoded |
| 17track gettrackinfo | 8s | Timeout |
| **Total pior caso** | **42s** | |

Apos o live tracking, o lookup faz sync (15s budget). Total possivel: **57s** — a 3s do timeout Vercel de 60s.

### Impacto

- Timeout 504 para usuario final do widget
- UX degradada — widget fica "carregando" por 50s+ antes de falhar
- Providers inoperantes (Correios 403, Cainiao 302) desperdicam 8s cada

## Acceptance Criteria

### 25.2.1 — Budget de tempo global em `trackWithBestProvider()`

- [x] Adicionar parametro `globalTimeoutMs` (default: 25000) em `trackWithBestProvider()`
- [x] Criar `AbortController` global que aborta apos `globalTimeoutMs`
- [x] Antes de cada provider, verificar tempo restante: se `< 500ms`, parar o loop
- [x] Cada provider individual limitado a `Math.min(remaining, 5000)` ms
- [x] Usar `Promise.race` entre execute do provider e abort global
- [x] Log quando global timeout interrompe o loop: `"Global timeout reached, stopping provider loop"`

### 25.2.2 — Reduzir timeout individual dos providers

- [x] Alterar timeout de cada provider de `8000ms` para `5000ms` em:
  - `trackViaCorreios()` — 8000 → 5000
  - `trackViaCainiao()` — 8000 → 5000
  - `trackViaTrackingMore()` — 8000 → 5000
  - `trackViaPostNL()` — 8000 → 5000
- [x] Alterar timeouts do 17track em `trackVia17track()`:
  - Register: `8000ms` → `5000ms`
  - GetTrackInfo: `8000ms` → `5000ms`

### 25.2.3 — Reduzir sleep do 17track

- [x] Alterar `await new Promise(r => setTimeout(r, 2000))` para `1000ms` em `trackVia17track()`

### 25.2.4 — Propagar AbortSignal para providers (opcional/futuro)

- [ ] Se possivel, passar o `AbortSignal` global para os providers individuais para cancelar fetch em andamento quando budget esgotar
- [ ] Requer adicionar `signal?: AbortSignal` na interface `ProviderEntry.execute()`
- [ ] NOTA: pode ser feito em story futura se complexidade for alta

## Dev Notes

### Codigo de referencia — budget global

```typescript
export async function trackWithBestProvider(
  trackingNumber: string,
  keys: CarrierKeys,
  trackVia17track: (numbers: string[], apiKey: string) => Promise<any[]>,
  providerOrder?: string[],
  globalTimeoutMs = 25_000
): Promise<TrackingResult | null> {
  const carrier = detectCarrierProvider(trackingNumber)
  const order = resolveProviderOrder(providerOrder ?? null)
  const deadline = Date.now() + globalTimeoutMs

  for (const providerName of order) {
    const remaining = deadline - Date.now()
    if (remaining <= 500) {
      log.warn("Global timeout reached, stopping provider loop", {
        trackingNumber, lastProvider: providerName,
      })
      break
    }

    const provider = PROVIDER_REGISTRY[providerName]
    if (!provider) continue
    if (!provider.canRun(keys, carrier)) continue

    const t0 = Date.now()
    log.info(`Trying ${provider.label}`, { trackingNumber, remainingMs: remaining })

    const providerTimeout = Math.min(remaining, 5_000)
    const controller = new AbortController()
    const timer = setTimeout(() => controller.abort(), providerTimeout)

    try {
      const result = await Promise.race([
        provider.execute(trackingNumber, keys, carrier, trackVia17track),
        new Promise<null>((resolve) => {
          controller.signal.addEventListener("abort", () => resolve(null), { once: true })
        }),
      ])

      const found = !!(result && result.events.length > 0)
      log.info("Provider attempt", {
        provider: providerName, trackingNumber,
        durationMs: Date.now() - t0, found,
      })

      if (found) return result
    } catch (err) {
      log.warn("Provider execution error", {
        provider: providerName,
        error: err instanceof Error ? err.message : String(err),
      })
    } finally {
      clearTimeout(timer)
    }
  }

  return null
}
```
