# Story 50.9 — Dashboard: Refund Metrics Card

## Story

**Como** admin que monitora a saude financeira dos clientes,
**Quero** ver um card de metricas de reembolsos no dashboard financeiro,
**Para que** eu tenha visibilidade rapida sobre volume e valor de reembolsos recentes.

## Contexto

O `BillingMetrics` (`src/components/dashboard/billing-metrics.tsx`) exibe cards com metricas financeiras. Esta story adiciona um card "Reembolsos (30d)" com valor total e contagem.

Os dados podem vir de:
1. **GET /api/financial/refunds** (story 50.5) com filtro de data — requer logica de agregacao no frontend
2. **Query direta na `refund_summaries` VIEW** via endpoint existente — mais eficiente

A abordagem recomendada e adicionar uma query ao endpoint que ja alimenta o BillingMetrics, ou criar uma query inline que busca os dados agregados.

### Referencia: Arquitetura

Ver secao 6.4 de `docs/architecture/refund-processing-architecture.md`.

## Acceptance Criteria

### AC 50.9.1 — Obter dados de refund para o dashboard

- [x] Buscar metricas de refund dos ultimos 30 dias
- [x] Dados necessarios: `total_value` (soma de amounts com status='processed') e `count` (numero de refunds)
- [x] Scoped por org_id do admin logado
- [x] Abordagem recomendada: adicionar query ao data fetching do BillingMetrics (ou ao endpoint que o alimenta)

```sql
-- Query de referencia (pode ser executada via Supabase client)
SELECT
  COUNT(*) AS refund_count,
  COALESCE(SUM(amount), 0) AS refund_total
FROM refunds
WHERE status = 'processed'
  AND processed_at >= NOW() - INTERVAL '30 days'
  AND client_id IN (SELECT id FROM clients WHERE org_id = :orgId)
```
