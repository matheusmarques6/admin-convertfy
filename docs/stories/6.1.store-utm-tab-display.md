## Contexto

O sistema ja possui logica completa de extracao e agregacao de UTM em `src/lib/integrations/shopify/report.ts`. A funcao `extractUtmParams()` processa `landing_site` e `referring_site` de cada pedido Shopify e agrega os resultados em `utmConversions` (bySource, byMedium, byCampaign). O endpoint `/api/integrations/shopify/report` ja retorna esses dados.

Porem, esses dados **nao sao visiveis em nenhum lugar do admin** (apenas parcialmente no portal do cliente). Esta story cria uma nova tab "UTM" na pagina `/stores/[id]` para que a agencia visualize os dados de conversao por UTM de cada loja.

**Multi-tenant:** Os dados sao isolados por loja (`store_id`) e organizacao (`org_id`). O endpoint de report ja usa `getStoreCredentials(storeId)` que valida acesso via `can_access_store()`. Nenhuma alteracao de seguranca necessaria nesta fase.

---

## Objetivo

Criar uma nova tab "UTM" dentro da pagina de detalhe da loja (`/stores/[id]`) que exibe os dados de conversao UTM ja calculados pelo report Shopify existente, sem alteracoes no backend.

## Arquitetura Tecnica

### Fluxo de Dados

```
1. Usuario acessa /stores/[id] > tab UTM
2. StoreUtmTab chama GET /api/integrations/shopify/report?store_id=X&period=30d
3. Backend (report.ts) busca pedidos Shopify, extrai UTM via extractUtmParams()
4. Response inclui orders.utmConversions com bySource, byMedium, byCampaign
5. StoreUtmTab renderiza cards + tabelas
```

### Interface de Dados (ja existente no report)

```typescript
// Response de /api/integrations/shopify/report → orders.utmConversions
interface UtmConversions {
  totalOrdersWithUtm: number
  utmTrackingRate: number  // 0-100
  bySource: Array<{ source: string; orders: number; revenue: number }>
  byMedium: Array<{ medium: string; orders: number; revenue: number }>
  byCampaign: Array<{ campaign: string; orders: number; revenue: number }>
}
```

### Estrutura do Componente

```typescript
// src/components/stores/store-utm-tab.tsx
interface StoreUtmTabProps {
  storeId: string
  period: "7d" | "30d" | "90d" | "all" | "custom"
  customDates?: { startDate: string; endDate: string }
}
```

### Posicao da Tab em store-detail-tabs.tsx

```
Overview | Campaigns | Flows | Report | **UTM** | Form | Briefing | Alerts | Rastreio | Settings
```

## Consideracoes de Seguranca

- **Sem alteracao de RLS**: Esta story e 100% frontend. Os dados vem do endpoint de report que ja valida acesso via `getStoreCredentials()` + `can_access_store()`.
- **Isolamento multi-tenant**: O `storeId` passado ao endpoint e validado no backend contra a organizacao do usuario autenticado.
- **Sem dados sensiveis**: UTM params sao metadados de marketing, nao contem PII.

---

## Edge Cases Documentados

- **Limite de 12.500 pedidos**: O endpoint `/api/integrations/shopify/report` processa ate ~12.500 pedidos (50 paginas x 250 pedidos). Lojas com mais pedidos no periodo selecionado terao dados UTM incompletos **sem aviso ao usuario**. Para V1, documentar esta limitacao. Para V2, considerar adicionar indicador "Dados parciais - loja com mais de 12.500 pedidos no periodo".
