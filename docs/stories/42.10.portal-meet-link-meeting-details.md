# Story 42.10 — Portal: Meet link e detalhes de reuniao

## Story

**Como** cliente no portal,
**Quero** ver o link do Google Meet e os participantes com status de confirmacao,
**Para que** eu possa entrar na reuniao facilmente e saber quem mais vai participar.

## Contexto

### Estado atual

- `NextMeetingCard` exibe proxima reuniao com countdown e link de acesso (`meeting_url` ja e usado)
- `MeetingsSection` lista reunioes futuras e recentes
- `PortalMeeting` type e read-only, nao inclui participantes nem meeting_url_source
- Dados vem via query segura (portal user so ve meetings do seu client_id)

### O que precisa mudar

1. `PortalMeeting` type inclui `meeting_url_source` e `participants`
2. `NextMeetingCard` mostra icone Meet quando source e 'google_meet'
3. `MeetingsSection` mostra participantes com status
4. Query de meetings do portal inclui dados adicionais

## Technical Notes

### Query de meetings do portal

```typescript
const { data: meetings } = await supabase
  .from('meetings')
  .select(`
    *,
    meeting_participants (
      id, participant_id, participant_type,
      is_organizer, response_status, email, google_rsvp_status
    )
  `)
  .eq('client_id', portalUser.client_id)
  .order('scheduled_at', { ascending: true })
```

### Mapear participantes para nomes

- `participant_type = 'org_member'`: buscar nome em `org_members` -> `profiles`
- `participant_type = 'profile'`: buscar nome em `profiles`
- Fallback: usar `email` se disponivel
