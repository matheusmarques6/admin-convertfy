# Story AK-10 — Relaxar Freshness Thresholds (Todos os Periodos)

## Story

**Como** operador do sistema,
**Quero** que os freshness thresholds de todos os periodos cached sejam mais relaxados,
**Para que** o cron consuma ~65% menos chamadas XS/dia por API key, viabilizando 42+ lojas dentro do cap diario.

## Contexto

### Problema

Apos AK-6 (que mudou 7d de 0 para 1h), a analise de freshness thresholds revelou que TODOS os periodos podem ser relaxados sem impacto perceptivel no dashboard. Os valores atuais em `data-status.ts:56-61`:

```typescript
export const PERIOD_FRESHNESS_THRESHOLDS: Record<CachedPeriod, number> = {
  "7d":  1 * 60 * 60_000,   // 1 hour (AK-6)
  "15d": 2 * 60 * 60_000,   // 2 hours
  "30d": 4 * 60 * 60_000,   // 4 hours
  "90d": 8 * 60 * 60_000,   // 8 hours
}
```

### Calculo de Impacto

```
Estimativa de report calls XS por key/dia (15 keys, 42 lojas):

ANTES (thresholds atuais):
  7d:  24 syncs/dia x ~3 lojas/key x 2 calls = ~144/key
  15d: 12 syncs/dia x ~3 lojas/key x 2 calls = ~72/key
  30d:  6 syncs/dia x ~3 lojas/key x 2 calls = ~36/key
  90d:  3 syncs/dia x ~3 lojas/key x 2 calls = ~18/key
  TOTAL: ~270/key/dia (excede cap de 225!)

DEPOIS (thresholds relaxados):
  7d:   8 syncs/dia x ~3 lojas/key x 2 calls = ~48/key
  15d:  6 syncs/dia x ~3 lojas/key x 2 calls = ~36/key
  30d:  4 syncs/dia x ~3 lojas/key x 2 calls = ~24/key
  90d:  2 syncs/dia x ~3 lojas/key x 2 calls = ~12/key
  TOTAL: ~120/key/dia (bem abaixo do cap!)
```

Reducao: ~270 → ~120/key/dia (**~55% menos**).

### Justificativa dos Novos Valores

| Periodo | Antes | Depois | Justificativa |
|---------|-------|--------|---------------|
| 7d  | 1h  | 3h  | Dashboard de 7d muda significativamente a cada 3h, nao a cada hora |
| 15d | 2h  | 4h  | Dados de 15 dias estabilizam rapido — 4h e suficiente |
| 30d | 4h  | 6h  | Dados de 30d mudam pouco hora a hora — 6h e conservador |
| 90d | 8h  | 12h | Dados de 90d sao quase estaticos — 12h (2x/dia) e adequado |

Consenso de 3 agentes (Architect, Data Engineer, Analyst): dados de dashboard com esses atrasos sao aceitaveis.
