# Story 15.6 -- Drop Bypass Policies + Add org_id to integrations

**Epic:** 15 - DB/RLS/Infra Bugs
**Prioridade:** CRITICA (seguranca)
**Tipo:** Security Hotfix
**Status:** In Progress (P0 DONE, P2 in progress)

---

## Problema

4 tabelas em producao possuem bypass RLS policies (`USING(true)`) que permitem qualquer usuario autenticado acessar dados de todas as organizacoes:

| Tabela | Policy | Comando | USING |
|--------|--------|---------|-------|
| `integrations` | "Authenticated users can manage integrations" | ALL | `true` |
| `contracts` | "Authenticated users can manage contracts" | ALL | `true` |
| `deals` | "Authenticated users can manage deals" | ALL | `true` |
| `reports` | "Authenticated users can manage reports" | ALL | `true` |

A tabela `integrations` e a mais critica: expoe credenciais Asaas (API key) para qualquer usuario logado. Combinado com rotas Asaas que nao filtram por org, permite ver dados financeiros de todas as contas.

## Impacto

- Qualquer usuario autenticado pode ler credenciais de integracao (Asaas API key)
- Dados financeiros (pagamentos, cobranyas, assinaturas) de todas as contas expostos
- Contratos, deals e relatorios de todas as orgs acessiveis

## Contexto de Risco

- Atualmente existe 1 organizacao em producao (Convertfy)
- Risco cross-tenant e teorico ate segunda org ser criada
- Correcao preventiva para evitar vazamento quando multi-tenant for ativado

## Fase 2: Migration

### AC 15.6.5 -- Adicionar org_id a integrations
- [ ] `ALTER TABLE integrations ADD COLUMN IF NOT EXISTS org_id UUID REFERENCES organizations(id)`
- [ ] Backfill: `UPDATE integrations SET org_id = '<org_id>' WHERE org_id IS NULL`
- [ ] Index: `CREATE INDEX IF NOT EXISTS idx_integrations_org_id ON integrations(org_id)`

### AC 15.6.6 -- Criar replacement policies ANTES de dropar bypass
Ordem critica: criar replacements PRIMEIRO, dropar bypass DEPOIS.

**integrations:**
- [ ] DROP "Users can view integrations" (antiga, is_admin only)
- [ ] CREATE "Org members can view integrations" SELECT → `is_admin() OR org_id = current_org_id()`
- [ ] CREATE "Admin or owner can manage integrations" ALL → `is_admin() OR is_org_owner(org_id)`

**contracts:**
- [ ] CREATE "Org members can view contracts" SELECT → `is_admin() OR can_access_client(client_id)`
- [ ] CREATE "Admin or owner can manage contracts" ALL → via client_id → clients.org_id

### AC 15.6.7 -- DROP bypass policies
- [ ] DROP "Authenticated users can manage integrations" ON integrations
- [ ] DROP "Authenticated users can manage contracts" ON contracts
- [ ] DROP "Authenticated users can manage deals" ON deals
- [ ] DROP "Authenticated users can manage reports" ON reports

### AC 15.6.8 -- Migration em transacao
- [ ] Toda a migration envolta em BEGIN/COMMIT
- [ ] Idempotente (IF EXISTS / IF NOT EXISTS em tudo)
