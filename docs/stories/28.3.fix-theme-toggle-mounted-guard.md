## Story

**Como** usuario com system preference dark mode,
**Quero** que o theme toggle renderize sem hydration mismatch,
**Para que** nao haja erro #418 ao carregar a pagina.

---

## Contexto

O sidebar (`src/components/layout/sidebar.tsx`, linhas 335, 343) e o portal theme toggle (`src/components/portal/theme-toggle.tsx`, linha 14) usam `useTheme()` para renderizar condicionalmente `<Sun>` vs `<Moon>`:

```typescript
{theme === "dark" ? <Sun /> : <Moon />}
```

`next-themes` retorna `theme = undefined` no SSR. No client, se `enableSystem` esta ativo e a system preference e `dark`, o theme resolve para `"dark"`, causando mismatch.

O `suppressHydrationWarning` no `<html>` **so protege o proprio elemento**, nao os filhos.

### Arquivos afetados

- `src/components/layout/sidebar.tsx` (linhas 335, 343)
- `src/components/portal/theme-toggle.tsx` (linha 14)
