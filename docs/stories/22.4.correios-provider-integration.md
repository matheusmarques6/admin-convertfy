# Story 22.4 -- Integracao Correios (API Rastro) como Provider Direto

## Status
Done

## Story

**Como** loja brasileira,
**Quero** que o rastreamento consulte a API dos Correios diretamente,
**Para que** meus clientes vejam dados de rastreamento mais rapidos e precisos, sem depender de intermediarios.

---

## Dependencia

> **Pre-requisito:** 22.1 implementada (cascade com AbortController, freshness guard).
> Correios sera adicionado como posicao 1 do cascade para lojas BR.

## Contexto

Correios e a transportadora mais usada no Brasil. Hoje, tracking numbers BR (`XX123456789BR`) sao rastreados via Cainiao ou TrackingMore — intermediarios que podem ter delay ou dados incompletos.

A **API Rastro** dos Correios e publica e gratuita, retorna dados direto da fonte. Para lojas BR, Correios deve ser o **TOP 1** no cascade, antes de qualquer outro provider.

### API Rastro dos Correios

- **Endpoint**: `https://proxyapp.correios.com.br/v1/sro-rastro/{codigoObjeto}`
- **Metodo**: GET
- **Autenticacao**: Nenhuma (API publica)
- **Rate limit**: Nao documentado oficialmente, usar com moderacao
- **Formato resposta**: JSON com array de eventos

### Nova ordem do cascade (lojas BR)

```
1. Correios   (se tracking BR, gratis)  ← NOVO, TOP 1
2. PostNL     (se carrier=postnl + key)
3. Cainiao    (SEMPRE, gratis)
4. TrackingMore (se key)
5. 17track    (SEMPRE ULTIMO)
```

### Para lojas NAO-BR

Cascade atual mantido (sem Correios):
```
1. PostNL → 2. Cainiao → 3. TrackingMore → 4. 17track
```

### Nota: Tracking numbers BR

Formato: 2 letras + 9 digitos + "BR" (ex: `SS987654321BR`).
O `detectCarrierProvider()` ja detecta esse padrao (regex `/^[A-Z]{2}\d{9}BR$/`).
A primeira letra indica o tipo de servico (S=SEDEX, J=PAC, R=Registrado, etc.).

### Nota: API Rastro pode retornar erro para tracking muito recente

Tracking postado ha poucos minutos pode retornar `"objeto nao encontrado"`. Isso e normal — o sistema dos Correios leva 1-4 horas para registrar. O cascade continua para Cainiao/TrackingMore que podem ter dados via integracao com os Correios.
