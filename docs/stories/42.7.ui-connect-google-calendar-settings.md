# Story 42.7 — UI: Botao Conectar Google Calendar no perfil/settings

## Story

**Como** admin user da plataforma,
**Quero** conectar e desconectar meu Google Calendar pela pagina de settings,
**Para que** eu controle a integracao e veja o status da minha conexao.

## Contexto

### Estado atual

- Nao existe UI para conectar Google Calendar per-user
- OAuth flow existe (story 42.3 refatorou) mas sem trigger na UI
- Nao existe endpoint para verificar status da conexao Google Calendar
- Nao existe endpoint para desconectar

### O que precisa mudar

1. Endpoint GET para status de conexao
2. Endpoint POST para desconexao
3. Card de integracao Google Calendar na pagina de settings
4. Banner de reconexao quando token invalido

## Acceptance Criteria

- [x] **AC 42.7.1**: Endpoint `GET /api/integrations/google/calendar/status`:
  - Retorna `{ connected, google_email, is_active, last_synced_at, sync_error }` via `getConnectionStatus()`
  - Autenticado pelo user logado

- [x] **AC 42.7.2**: Endpoint `POST /api/integrations/google/calendar/disconnect`:
  - Chama `disconnectGoogle()` do google-auth.service
  - Retorna `{ success: true }`
  - Autenticado pelo user logado

- [x] **AC 42.7.3**: Card "Google Calendar" na pagina de settings do admin (secao Integracoes):
  - **Desconectado**: icone Google Calendar + titulo + descricao + botao "Conectar Google Calendar"
  - **Conectado e ativo**: icone Google Calendar + email conectado + badge "Conectado" verde + botao "Desconectar"
  - **Conectado mas inativo**: icone Google Calendar + email + badge "Erro" vermelho + mensagem de erro + botao "Reconectar"

- [x] **AC 42.7.4**: Botao "Conectar" redirect para `GET /api/integrations/google/authorize?scope=calendar&context=admin`

- [x] **AC 42.7.5**: Botao "Desconectar": modal de confirmacao ("Tem certeza? Reunioes futuras nao serao mais sincronizadas."), chama endpoint disconnect, atualiza UI

- [x] **AC 42.7.6**: Quando token revogado/expirado (`is_active = false`):
  - Banner amarelo no topo da pagina de meetings: "Seu Google Calendar esta desconectado. Reconecte para sincronizar reunioes."
  - Botao "Reconectar" no banner que redirect para authorize

- [x] **AC 42.7.7**: Se user sem Calendar conectado tenta criar reuniao com Meet (checkbox ON no dialog):
  - Mostrar inline alert: "Conecte seu Google Calendar para criar reunioes com Meet automatico"
  - Link "Conectar agora" que abre settings em nova aba

## Technical Notes

### Endpoint de status

```typescript
// GET /api/integrations/google/calendar/status
import { getConnectionStatus } from '@/lib/services/google-auth.service'

export async function GET(request: NextRequest) {
  const supabase = await createClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })

  const status = await getConnectionStatus(user.id, 'profile')
  return NextResponse.json(status)
}
```

### Hook customizado sugerido

```typescript
function useGoogleCalendarStatus() {
  const { data, error, mutate } = useSWR('/api/integrations/google/calendar/status')
  return {
    connected: data?.connected ?? false,
    googleEmail: data?.google_email,
    isActive: data?.is_active ?? false,
    syncError: data?.sync_error,
    refresh: mutate,
    isLoading: !data && !error,
  }
}
```
