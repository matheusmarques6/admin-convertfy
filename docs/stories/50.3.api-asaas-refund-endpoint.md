# Story 50.3 — API Endpoint: POST /api/integrations/asaas/refund

## Story

**Como** admin que precisa reembolsar uma cobranca Asaas,
**Quero** um endpoint que valide a requisicao, chame o RefundService, e retorne o status do reembolso,
**Para que** a UI admin (story 50.7) tenha uma API para disparar refunds via Asaas.

## Contexto

Este endpoint e o trigger para refunds de cobranças Asaas (invoices). O fluxo e **assincrono**: o endpoint insere o refund com status 'requested' e retorna imediatamente. A confirmacao vem via webhook (story 50.6).

O endpoint segue o padrao existente dos routes em `src/app/api/integrations/asaas/`:
- `requireAuth()` para autenticacao
- `resolveOrgId()` para scoping multi-tenant
- `errorResponse()` para error handling padronizado
- Zod para validacao de request body

### AC 50.3.2 — Validacao de request body com Zod

- [x] Schema Zod para body:
  ```typescript
  const refundSchema = z.object({
    invoice_id: z.string().uuid(),
    amount: z.number().positive().optional(),
    reason: z.string().min(3).max(500),
  })
  ```
- [x] Parse body com `refundSchema.safeParse()` — se invalido, retornar 400 com detalhes

### AC 50.3.3 — Autenticacao e autorizacao

- [x] Seguir padrao existente nos routes Asaas (ver `charges/route.ts`):
  ```typescript
  const supabase = await createClient()
  const user = await requireAuth(supabase)
  const orgId = await resolveOrgId(user.id)
  ```
- [x] Passar `orgId` e `user.id` para o service

### AC 50.3.4 — Chamar RefundService e retornar response

- [x] Chamar `initiateAsaasRefund({ invoiceId, orgId, userId, amount, reason })`
- [x] Response 200:
  ```json
  {
    "refund_id": "uuid",
    "status": "requested",
    "original_amount": 500.00,
    "refund_amount": 500.00
  }
  ```
- [x] Erros do service propagam via `errorResponse()`:
  - 400: invoice nao encontrada, status != paid, sem asaas_id, valor invalido
  - 403: org_id mismatch
  - 409: ja reembolsada totalmente
  - 429: rate limit excedido
  - 502: Asaas API falhou

### AC 50.3.5 — Error handling padronizado

- [x] Wrap do handler em try/catch com `errorResponse(request, error, 'POST /api/integrations/asaas/refund')`
- [x] Seguir mesmo padrao de error handling dos outros routes em `src/app/api/integrations/asaas/`
