# Story 45.2 — Fix or Remove Broken Week View Navigation

## Status: Ready for Review
## Effort: MEDIUM (1-2h)
## Priority: CRITICAL

## Context

The week view has 3 compounding bugs:
1. `goToPrev`/`goToNext` call `goToPreviousMonth()`/`goToNextMonth()` even in week mode — jumps entire months
2. `weekStart`/`weekEnd` useMemo depends on `[year, month]` but `currentDate` is always the 1st — week view always shows the same week
3. `goToToday` sets actual today's date (e.g., March 15) while navigation always sets 1st of month — inconsistent week after pressing "Today"

## Decision Required

**Option A: Fix properly** — Add week-level navigation state and step by 7 days
**Option B: Remove week view** — Delete the toggle and weekly rendering code, simplify the page

Recommendation: **Option B (remove)** if week view is not actively used by clients. It reduces page complexity significantly. Can re-add later as a proper component in Phase 3.

## Files

- `src/app/client/campaigns/page.tsx` — week view rendering + navigation
- `src/lib/hooks/use-portal-campaigns-calendar.ts` — goToToday inconsistency
