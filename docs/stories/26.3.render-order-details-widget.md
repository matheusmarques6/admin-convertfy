## Story

**Como** consumidor que rastreia seu pedido no widget,
**Quero** ver a imagem, nome e detalhes dos produtos que comprei,
**Para que** eu tenha contexto visual do que esta sendo entregue.

---

## Contexto

O widget hoje exibe: status badge, info grid, progress stepper e timeline de eventos. Falta uma secao de "Detalhes do Pedido" mostrando os produtos com thumbnail, nome, quantidade e preco.

### Dados disponiveis apos Story 26.2

```json
{
  "order": {
    "order_name": "#1001",
    "total_price": 199.00,
    "currency": "BRL",
    "line_items": [
      {
        "title": "Camiseta Premium",
        "quantity": 2,
        "price": "79.90",
        "image_url": "https://cdn.shopify.com/s/files/..."
      }
    ]
  }
}
```

---

## Acceptance Criteria

### 26.3.1 — Secao "Detalhes do Pedido" no widget

- [ ] Adicionar secao entre o Progress Stepper e a Timeline de Eventos
- [ ] Secao com header colapsavel: "Detalhes do Pedido" (esquerda) + order_name (direita)
- [ ] Default: expandido
- [ ] Click no header colapsa/expande com animacao suave

### 26.3.2 — Card de produto

- [ ] Cada line_item renderiza como row horizontal:
  - Thumbnail 64x64 (border-radius 6px, object-fit cover)
  - Titulo do produto (max 2 linhas, truncado com ellipsis)
  - Quantidade + preco: `Qtd: 2  .  R$ 79,90 /un`
- [ ] Separador dashed entre itens (nao apos o ultimo)
- [ ] Preco formatado com `toLocaleString(lang, { style:'currency', currency })` usando currency do pedido

### 26.3.3 — Linha de total

- [ ] Abaixo dos produtos, linha com borda top solid
- [ ] Texto alinhado a direita: `Total: R$ 199,00`
- [ ] Formatado com currency do pedido
- [ ] Font-weight 600

### 26.3.4 — Fallback para imagem ausente

- [ ] Quando `image_url` e null/undefined/vazio, exibir placeholder:
  - Fundo `#f1f5f9` (light gray)
  - Icone de pacote SVG centralizado (24x24, cor `#94a3b8`)
- [ ] Usar `onerror` no `<img>` para trocar para placeholder se URL falhar

### 26.3.5 — Tratamento de muitos itens (>3)

- [ ] Se `line_items.length > 3`, mostrar primeiros 3 itens
- [ ] Exibir row extra: icone de pacotes + `"+ N itens"` + link `"Ver todos"` na cor principal
- [ ] Click em "Ver todos" expande todos os itens, texto muda para "Ver menos"

### 26.3.6 — Esconder secao quando sem dados

- [ ] Se `line_items` e null, undefined, ou array vazio: NAO renderizar a secao
- [ ] Widget vai direto do Progress Stepper para Timeline

### 26.3.7 — Responsividade

- [ ] Em telas < 360px: thumbnail reduz para 48x48
- [ ] Layout horizontal (thumbnail + texto) se mantem em todas as larguras
- [ ] Texto de preco faz wrap natural se necessario

### 26.3.8 — Otimizacao de imagens

- [ ] Adicionar `?width=128` na URL APENAS se for `cdn.shopify.com` (nao aplicar em outras CDNs que podem quebrar com query params)
- [ ] Guard: `url.includes('cdn.shopify.com') ? url + '?width=128' : url`
- [ ] Atributo `loading="lazy"` em todas as `<img>` de produto
- [ ] Atributo `alt` com titulo do produto

### 26.3.9 — Traducao dos labels

- [ ] Adicionar em TRANSLATIONS para todos os idiomas:
  - `order_details`: "Detalhes do Pedido" / "Order Details" / "Detalles del Pedido" / etc.
  - `quantity_short`: "Qtd" / "Qty" / "Cant" / etc.
  - `per_unit`: "/un" / "/ea" / "/ud" / etc.
  - `total`: "Total" (igual em todos)
  - `more_items`: "+ {n} itens" / "+ {n} items" / etc.
  - `see_all`: "Ver todos" / "See all" / etc.
  - `see_less`: "Ver menos" / "See less" / etc.
  - `image_unavailable`: "Imagem indisponivel" (aria-label)

|----------|-----|

### Acessibilidade

- Section header: `role="button"`, `aria-expanded`, `tabindex="0"`, ativa com Enter/Space
- Content: `role="region"`, `aria-label`
- Product list: `role="list"` + `role="listitem"`
- Images: `alt="{product_title}"`
- Fallback: `aria-label="Imagem indisponivel"`
- "Ver todos": focusable, ativa com Enter
- Focus ring: 2px solid data-color, offset 2px

## Notas QA

- **line_items conta variantes**: Um pedido Shopify com 2 produtos mas 5 line_items (tamanhos diferentes) vai contar como 5 itens. O collapse >3 se aplica por line_item, nao por produto. Isso e aceitavel.
- **Live tracking sem line_items**: Resultados de live tracking (sem pedido no DB) terao `line_items: []`. A secao simplesmente nao renderiza (AC 26.3.6).
- **Currency formatting**: `toLocaleString` depende do browser do consumidor. Browsers muito antigos podem nao suportar todos os locales. Risco baixo.
