## Story

**Como** consumidor que rastreia seu pedido no widget,
**Quero** ver a imagem, nome e detalhes dos produtos que comprei,
**Para que** eu tenha contexto visual do que esta sendo entregue.

---

## Contexto

O widget hoje exibe: status badge, info grid, progress stepper e timeline de eventos. Falta uma secao de "Detalhes do Pedido" mostrando os produtos com thumbnail, nome, quantidade e preco.

### Dados disponiveis apos Story 26.2

```json
{
  "order": {
    "order_name": "#1001",
    "total_price": 199.00,
    "currency": "BRL",
    "line_items": [
      {
        "title": "Camiseta Premium",
        "quantity": 2,
        "price": "79.90",
        "image_url": "https://cdn.shopify.com/s/files/..."
      }
    ]
  }
}
```

---

## Acceptance Criteria

### 26.3.1 — Secao "Detalhes do Pedido" no widget

- [x] Adicionar secao entre o Progress Stepper e a Timeline de Eventos
- [x] Secao com header colapsavel: "Detalhes do Pedido" (esquerda) + order_name (direita)
- [x] Default: colapsado (click para expandir)
- [x] Click no header colapsa/expande com animacao suave

### 26.3.2 — Card de produto

- [x] Cada line_item renderiza como row horizontal:
  - Thumbnail 56x56 (border-radius 8px, object-fit cover)
  - Titulo do produto (1 linha, truncado com ellipsis)
  - Quantidade + preco unitario
- [x] Separador solid entre itens (border-bottom, nao apos o ultimo)
- [x] Preco formatado com `toFixed(2)` + currency prefix

### 26.3.3 — Linha de total

- [x] Abaixo dos produtos, linha com borda top solid
- [x] Texto alinhado: label esquerda, valor direita
- [x] Formatado com currency do pedido
- [x] Font-weight 600/700

### 26.3.4 — Fallback para imagem ausente

- [x] Quando `image_url` e null/undefined/vazio, exibir placeholder:
  - Fundo `#f1f5f9` (light gray)
  - Icone de imagem SVG centralizado (24x24, cor `#cbd5e1`)
- [x] Usar `onerror` no `<img>` para trocar para placeholder se URL falhar

### 26.3.5 — Tratamento de muitos itens (>3)

- [x] Se `line_items.length > 3`, mostrar primeiros 3 itens
- [x] Exibir botao: `"+ N itens"` na cor principal
- [x] Click em botao expande todos os itens, texto muda para "Ver menos"

### 26.3.6 — Esconder secao quando sem dados

- [x] Se `line_items` e null, undefined, ou array vazio: NAO renderizar a secao
- [x] Widget vai direto do Progress Stepper para Timeline

### 26.3.7 — Responsividade

- [x] Em telas < 680px: thumbnail reduz para 48x48
- [x] Layout horizontal (thumbnail + texto) se mantem em todas as larguras
- [x] Texto de preco faz wrap natural se necessario

### 26.3.8 — Otimizacao de imagens

- [x] Adicionar `?width=128` na URL APENAS se for `cdn.shopify.com` (nao aplicar em outras CDNs que podem quebrar com query params)
- [x] Guard: verifica se ja tem `width=` antes de adicionar
- [x] Atributo `loading="lazy"` em todas as `<img>` de produto
- [x] Atributo `alt` com titulo do produto

### 26.3.9 — Traducao dos labels

- [x] Adicionar em TRANSLATIONS para todos os 6 idiomas (pt-BR, en, es, fr, de, it):
  - `order_details`, `quantity_short`, `per_unit`, `total`, `more_items`, `see_all`, `see_less`, `image_unavailable`

### Acessibilidade

- Section header: `role="button"`, `aria-expanded`, `tabindex="0"`, ativa com Enter/Space
- Content: `role="region"`, `aria-label`
- Product list: `role="list"` + `role="listitem"`
- Images: `alt="{product_title}"`
- Fallback: `aria-label="Imagem indisponivel"`
- "Ver todos": focusable, ativa com Enter
- Focus ring: 2px solid data-color, offset 2px

## Notas QA

- **line_items conta variantes**: Um pedido Shopify com 2 produtos mas 5 line_items (tamanhos diferentes) vai contar como 5 itens. O collapse >3 se aplica por line_item, nao por produto. Isso e aceitavel.
- **Live tracking sem line_items**: Resultados de live tracking (sem pedido no DB) terao `line_items: []`. A secao simplesmente nao renderiza (AC 26.3.6).
- **Currency formatting**: `toLocaleString` depende do browser do consumidor. Browsers muito antigos podem nao suportar todos os locales. Risco baixo.
