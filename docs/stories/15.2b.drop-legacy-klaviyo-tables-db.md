# Story 15.2b — DROP das Tabelas Legacy Klaviyo (pós-migração)

## Contexto

Após a Story 15.2 remover todas as referências de código às tabelas legacy, esta story executa o DROP das 6 tabelas criadas pela migration `20250125_10_klaviyo_metrics.sql`.

**Pré-condição obrigatória:** Story 15.2 deve estar 100% concluída e grep em `src/` deve confirmar zero referências antes de executar esta story.

## Objetivo

**Como** engenheiro de banco de dados,
**Quero** dropar as 6 tabelas legacy do banco de dados,
**Para que** o schema fique limpo sem tabelas não utilizadas.

## Acceptance Criteria

- [ ] **15.2b.1** — Grep confirma zero referências às tabelas em `src/` antes de aplicar a migration.
- [ ] **15.2b.2** — Migration `20260304_drop_legacy_klaviyo_tables.sql` dropa os 5 triggers com os nomes reais (confirmados na migration original).
- [ ] **15.2b.3** — Migration dropa as 6 tabelas na ordem correta (child tables primeiro).
- [ ] **15.2b.4** — Migration dropa as 3 funções auxiliares órfãs (`update_klaviyo_updated_at`, `check_campaign_metrics_alerts`, `create_metrics_snapshot`).
- [ ] **15.2b.5** — Migration aplica sem erros.
- [ ] **15.2b.6** — Supabase Dashboard não exibe as tabelas nem as funções removidas.

## Arquitetura Técnica

Nomes reais dos triggers e funções confirmados via leitura de `20250125_10_klaviyo_metrics.sql`:

| Trigger | Tabela | Função chamada |
|---------|--------|----------------|
| `trigger_klaviyo_campaigns_updated` | `klaviyo_campaigns` | `update_klaviyo_updated_at()` |
| `trigger_campaign_metrics_updated` | `campaign_metrics` | `update_klaviyo_updated_at()` |
| `trigger_sync_config_updated` | `klaviyo_sync_config` | `update_klaviyo_updated_at()` |
| `trigger_check_metrics_alerts` | `campaign_metrics` | `check_campaign_metrics_alerts()` |
| `trigger_create_metrics_snapshot` | `campaign_metrics` | `create_metrics_snapshot()` |

Funções auxiliares a dropar (criadas pela migration original, ficam órfãs após DROP das tabelas):
- `update_klaviyo_updated_at()`
- `check_campaign_metrics_alerts()`
- `create_metrics_snapshot()`

**Arquivo:** `supabase/migrations/20260304_drop_legacy_klaviyo_tables.sql`

```sql
-- Drop legacy Klaviyo tables (safe after Story 15.2 removes all code references)
-- Tables from migration 20250125_10_klaviyo_metrics.sql
--
-- Trigger names confirmed from the original migration file (corrected from v1 story).

-- Drop triggers explicitly before tables
-- (kampanye triggers)
DROP TRIGGER IF EXISTS trigger_klaviyo_campaigns_updated ON klaviyo_campaigns;
-- (campaign_metrics triggers)
DROP TRIGGER IF EXISTS trigger_campaign_metrics_updated ON campaign_metrics;
DROP TRIGGER IF EXISTS trigger_check_metrics_alerts ON campaign_metrics;
DROP TRIGGER IF EXISTS trigger_create_metrics_snapshot ON campaign_metrics;
-- (sync_config triggers)
DROP TRIGGER IF EXISTS trigger_sync_config_updated ON klaviyo_sync_config;

-- Drop tables in dependency order (child tables first)
DROP TABLE IF EXISTS campaign_alerts CASCADE;
DROP TABLE IF EXISTS campaign_metrics_history CASCADE;
DROP TABLE IF EXISTS campaign_metrics CASCADE;
DROP TABLE IF EXISTS klaviyo_campaigns CASCADE;
DROP TABLE IF EXISTS klaviyo_sync_jobs CASCADE;
DROP TABLE IF EXISTS klaviyo_sync_config CASCADE;

-- Drop orphan auxiliary functions (no longer needed after tables are gone)
DROP FUNCTION IF EXISTS update_klaviyo_updated_at() CASCADE;
DROP FUNCTION IF EXISTS check_campaign_metrics_alerts() CASCADE;
DROP FUNCTION IF EXISTS create_metrics_snapshot() CASCADE;
```
