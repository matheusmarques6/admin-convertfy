# Story 36.2 — Unificar Design System do Wizard (Tokens shadcn)

## Contexto

O wizard portal (`/portal/onboarding/wizard/page.tsx`) tem ~30 instancias de cores hardcoded que ignoram os tokens do design system shadcn. Cada input repete a mesma string monstro:

```
className="h-10 bg-slate-50 dark:bg-[#1A1F2E] border-slate-200 dark:border-slate-700/40 text-slate-800 dark:text-slate-100"
```

Enquanto o form publico usa corretamente `<Card>`, `<Label>`, `bg-muted`, `text-foreground` etc.

### Cores hardcoded no wizard
- `bg-[#F8F9FB]`, `dark:bg-[#0B0E14]` (backgrounds de pagina)
- `bg-[#151922]` (card background)
- `bg-[#1A1F2E]` (input background)
- `text-slate-700/500/400` (labels, descriptions)
- `border-slate-200`, `dark:border-slate-700/40` (borders)
- `text-[13px]` (tamanho fora da escala Tailwind)

## Objetivo

Substituir todas as cores hardcoded por tokens semanticos do shadcn/Tailwind e normalizar tipografia.

## Criterios de Aceitacao

- [x] **AC 36.2.1**: Substituir `bg-[#F8F9FB] dark:bg-[#0B0E14]` por `bg-background` no container da pagina
- [x] **AC 36.2.2**: Substituir `bg-[#151922]` por `bg-card` no card principal
- [x] **AC 36.2.3**: Remover classes hardcoded de todos os `<Input>` — usar estilo padrao shadcn (sem `bg-slate-50 dark:bg-[#1A1F2E]`)
- [x] **AC 36.2.4**: Remover classes hardcoded de todos os `<SelectTrigger>` e `<SelectContent>`
- [x] **AC 36.2.5**: Substituir `text-[13px]` por `text-sm` em todos os `<Label>` — usar `<Label>` padrao sem override de cor
- [x] **AC 36.2.6**: Substituir `text-slate-500 dark:text-slate-400` por `text-muted-foreground` em descricoes
- [x] **AC 36.2.7**: Substituir `text-slate-800 dark:text-slate-100` por `text-foreground` em titulos
- [x] **AC 36.2.8**: Usar `<Card>` shadcn para o container principal (consistente com form publico) ou manter `div` com `bg-card border rounded-2xl`
- [x] **AC 36.2.9**: Resultado visual deve ser identico ou melhor em light + dark mode
- [x] **AC 36.2.10**: Zero cores hex (`#`) ou `slate-*` hardcoded restantes no arquivo

## Impacto por Disciplina
