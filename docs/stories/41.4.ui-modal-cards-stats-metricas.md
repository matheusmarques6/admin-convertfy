# Story 41.4 — UI: Modal Enriquecido, Cards com Preview, Stats Atualizados

## Story

**Como** portal user visualizando o calendario de campanhas,
**Quero** ver metricas de performance diretamente nos cards do calendario e no modal de detalhe,
**Para que** eu tenha visibilidade imediata do impacto das minhas campanhas sem sair do calendario.

## Contexto

### Estado atual

- Cards do calendario mostram apenas nome + icone de canal
- Modal de detalhe mostra contagens brutas (recipients, opened, clicked, converted, revenue)
- Stats cards no topo: Enviadas, Agendadas, Destinatarios, Receita

### Mudancas

1. **Modal enriquecido** — grid 2x3 de metricas para campanhas sent com metricas Klaviyo
2. **Cards com preview** — open rate + revenue compacto nos cards do calendario
3. **Stats cards atualizados** — substituir "Agendadas" por "Taxa de Abertura" media
4. **Revenue badge** — no modal de dia com multiplas campanhas

### Referencia visual

O dashboard da agencia (`src/app/admin/campaigns/`) ja mostra metricas ricas. A implementacao do portal deve seguir o mesmo padrao visual mas adaptado ao layout do portal.

- [x] Para campanhas `sent` com `hasKlaviyoMetrics = true`, adicionar grid 2x3 de metricas:

### 41.4.3 — Atualizar stats cards do topo

- [x] Substituir card "Agendadas" por "Taxa de Abertura":
  - Valor: media ponderada do `open_rate` das campanhas sent com metricas
  - Ponderacao por `recipients` (campanhas com mais destinatarios pesam mais)
  - Formula: `sum(open_rate * recipients) / sum(recipients)` das campanhas com `hasKlaviyoMetrics = true`
  - Se nenhuma campanha tem metricas, mostrar `--`
  - Formato: `XX.X%`
- [x] Manter cards existentes:
  - **Enviadas**: count de campanhas com status `sent`
  - **Destinatarios**: sum de `recipients` das campanhas sent
  - **Receita**: sum de `revenue` das campanhas sent com metricas
- [x] Calcular valores a partir dos dados ja retornados pela API (nao fazer fetch adicional):
  ```typescript
  const sentCampaigns = campaigns.filter(c => c.status === 'sent')
  const withMetrics = sentCampaigns.filter(c => c.hasKlaviyoMetrics)

  const totalRecipients = sentCampaigns.reduce((s, c) => s + (c.recipients ?? 0), 0)
  const totalRevenue = withMetrics.reduce((s, c) => s + (c.revenue ?? 0), 0)

  const weightedOpenRate = withMetrics.length > 0
    ? withMetrics.reduce((s, c) => s + (c.openRate ?? 0) * (c.recipients ?? 0), 0)
      / withMetrics.reduce((s, c) => s + (c.recipients ?? 0), 0)
    : null
  ```

**Arquivo:** `src/app/client/campaigns/page.tsx`
