# Story 40.6 — Shared Onboarding Step Card Component

## Story

**Como** membro da equipe,
**Quero** ver o mesmo card visual de etapa de onboarding tanto no kanban de onboarding quanto no meu board pessoal,
**Para que** a experiencia seja consistente e eu reconheca imediatamente do que se trata.

## Contexto

Atualmente existem dois componentes de card separados:
- `src/components/board/task-card.tsx` — card de task no board pessoal
- `src/components/onboarding/store-onboarding-card.tsx` — card de onboarding no kanban

Para o sync funcionar visualmente, precisamos de um componente compartilhado que:
- Mostre informacoes do step (nome, assignee, status, cliente, loja)
- Funcione em ambos os contextos (board e onboarding kanban)
- Permita acoes contextuais (completar, bloquear, ver detalhes)
- Mostre indicador visual de origem quando exibido no board ("Onboarding" badge)

## Technical Notes

### Interface do componente

```typescript
interface OnboardingStepCardProps {
  step: {
    id: string
    name: string
    description?: string
    category: string
    status: OnboardingStepStatus
    assigned_to?: string
    depends_on_step_ids?: string[]
    due_date?: string
    completed_at?: string
    completed_by?: string
    notes?: string
  }
  // Dados contextuais
  client?: { name: string; company?: string }
  store?: { store_name: string }
  assignee?: { name: string; avatar_url?: string }
  blockedByNames?: string[]  // Nomes dos steps que bloqueiam este

  // Contexto de exibicao
  context: "board" | "onboarding"

  // Callbacks
  onStatusChange?: (stepId: string, newStatus: OnboardingStepStatus) => void
  onComplete?: (stepId: string) => void
  onClick?: (stepId: string) => void

  // Visual
  isDragging?: boolean
  className?: string
}
```

### Integracao com task-card.tsx

No `task-card.tsx` existente, detectar tasks de onboarding step e renderizar o componente compartilhado:

```typescript
// Dentro de TaskCard render:
if (task.source_type === "auto_onboarding_step" && task.metadata?.step_data) {
  return (
    <OnboardingStepCard
      step={task.metadata.step_data}
      client={task.metadata.client}
      store={task.metadata.store}
      context="board"
      onComplete={() => onStatusChange(task.id, "completed")}
      onClick={() => onTaskClick(task.id)}
    />
  )
}
// Fallback: renderizar task-card normal
```
