# Story 14.1 — Kanban Onboarding: Link Direto para Loja no Dropdown

## Contexto

O componente `OnboardingKanban` exibe cards para cada processo de onboarding em andamento. Cada card possui um menu dropdown com ações rápidas (Ver Etapas, Atribuir Responsável, Ver Cliente). Operadores precisavam navegar para a loja associada ao onboarding, mas tinham que ir primeiro à página do cliente e depois encontrar a loja manualmente — um fluxo desnecessariamente longo.

Adicionalmente, o item "Ver Cliente" no dropdown não possuía ícone, tornando-o visualmente inconsistente com os demais itens que já tinham ícones.

## Objetivo

**Como** operador no kanban de onboarding,
**Quero** ver um link direto "Ver Loja" no dropdown de ações do card,
**Para que** eu possa navegar imediatamente para a loja associada ao onboarding sem precisar passar pela página do cliente.

## Acceptance Criteria

- [x] **14.1.1** — O dropdown de ações de cada card de onboarding exibe a opção "Ver Loja" quando `onboarding.store_id` está presente (não nulo).
- [x] **14.1.2** — O link "Ver Loja" navega para `/stores/{store_id}` usando uma tag `<a>` nativa (compatível com `DropdownMenuItem asChild`).
- [x] **14.1.3** — O item "Ver Loja" exibe o ícone `Store` da biblioteca `lucide-react` com `className="mr-2 h-4 w-4"`, seguindo o padrão visual dos demais itens do dropdown.
- [x] **14.1.4** — O item "Ver Loja" é renderizado condicionalmente: quando `store_id` é `null` ou `undefined`, o item NÃO aparece no dropdown.
- [x] **14.1.5** — O item "Ver Loja" é posicionado antes do item "Ver Cliente", dentro do bloco após o `DropdownMenuSeparator`.
- [x] **14.1.6** — O item "Ver Cliente" recebe o ícone `Building2` da biblioteca `lucide-react`, tornando-o visualmente consistente com os demais itens do dropdown.
- [x] **14.1.7** — Os ícones `Store` e `Building2` são importados corretamente de `lucide-react` no componente.

## Arquitetura Tecnica

### Arquivo Modificado

**`src/components/onboarding/onboarding-kanban.tsx`** — Único arquivo modificado. Nenhuma alteração de backend, schema ou API necessária, pois `store_id` já existia na query do onboarding.

### Trecho Implementado

```tsx
// Dentro do DropdownMenuContent, após o DropdownMenuSeparator:
{onboarding.store_id && (
  <DropdownMenuItem asChild>
    <a href={`/stores/${onboarding.store_id}`}>
      <Store className="mr-2 h-4 w-4" />
      Ver Loja
    </a>
  </DropdownMenuItem>
)}
<DropdownMenuItem asChild>
  <a href={`/clients/${onboarding.client_id}`}>
    <Building2 className="mr-2 h-4 w-4" />
    Ver Cliente
  </a>
</DropdownMenuItem>
```

### Imports Adicionados (ou confirmados)
- `Store` de `lucide-react`
- `Building2` de `lucide-react`
