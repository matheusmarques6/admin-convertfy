## Story

**Como** usuario admin que gera copies de campanhas,
**Quero** filtrar e buscar lojas rapidamente no seletor da sub-aba Copy,
**Para que** eu consiga selecionar as lojas corretas sem scroll excessivo quando ha muitas lojas cadastradas.

---

## Contexto

O seletor de lojas atual (`InlineStoreSelector`) dentro de `CopyTab` e uma grid simples 2 colunas com cards clicaveis. Nao possui filtros, busca ou agrupamento visual. Quando o numero de lojas cresce (10+), encontrar e selecionar lojas especificas se torna trabalhoso.

A API `GET /api/stores?active=true` ja retorna `country`, `language` e `client { name, company }` para cada loja, mas o tipo `PortalStore` no componente so mapeia `id`, `store_name` e `platform`. Os dados necessarios ja existem no response -- basta mapeá-los.

### Fora de Escopo

- Formulario de campanha (nome, data, doc referencia) -- permanece como esta
- Historico de geracoes / CampaignHistoryList -- permanece como esta
- CopyGenerationBoard (board de tarefas) -- permanece como esta
- StoreSelector de `src/components/campaigns/store-selector.tsx` (componente separado usado no AddStoresModal) -- NAO sera modificado

### 20.14.2 -- Toolbar de filtros rapidos

- [x] Adicionar uma barra de ferramentas ACIMA da grid de lojas, dentro do `InlineStoreSelector`
- [x] Layout da toolbar: flex row com gap, empilha em mobile (flex-wrap)
- [x] Componentes da toolbar:

     - Placeholder: "Buscar loja..."
     - Filtra por `store_name` em tempo real (case-insensitive, `includes`)
     - Debounce NAO necessario (filtragem client-side em lista pequena)
  2. **Dropdown Pais** (`Select` do shadcn/ui)
     - Label placeholder: "Todos os paises"
     - Opcoes: lista dinamica e unica dos `country` das lojas carregadas
     - Exibir codigo do pais (ex: "BR", "US", "PT")
     - Opcao "Todos" para limpar filtro
  3. **Dropdown Idioma** (`Select` do shadcn/ui)
     - Label placeholder: "Todos os idiomas"
     - Opcoes: lista dinamica e unica dos `language` das lojas carregadas
     - Exibir codigo do idioma (ex: "pt-BR", "en-US")
     - Opcao "Todos" para limpar filtro
- [x] Filtros sao **cumulativos**: busca + pais + idioma aplicados simultaneamente
- [x] Estado dos filtros: `useState` local no `InlineStoreSelector`
  ```typescript
  const [search, setSearch] = useState("")
  const [countryFilter, setCountryFilter] = useState<string>("all")
  const [languageFilter, setLanguageFilter] = useState<string>("all")
  ```
- [x] Derivar `filteredStores` com `useMemo`:
  ```typescript
  const filteredStores = useMemo(() => {
    return stores.filter((s) => {
      const matchesSearch = s.store_name.toLowerCase().includes(search.toLowerCase())
      const matchesCountry = countryFilter === "all" || s.country === countryFilter
      const matchesLanguage = languageFilter === "all" || s.language === languageFilter
      return matchesSearch && matchesCountry && matchesLanguage
    })
  }, [stores, search, countryFilter, languageFilter])
  ```
- [x] A grid renderiza `filteredStores` em vez de `stores`

### 20.14.4 -- Botoes "Selecionar todas" / "Limpar selecao" contextuais

  ```typescript
    onChange(merged)
  }
  ```
- [x] "Limpar selecao": remove apenas IDs das `filteredStores` do `selected`

  ```typescript
    onChange(selected.filter((id) => !filteredIds.has(id)))
  ```

## Riscos

| Risco | Probabilidade | Impacto | Mitigacao |
|-------|---------------|---------|-----------|
| Lojas sem `country`/`language` preenchido (valores default) | Media | Baixo | Usar defaults 'BR' / 'pt-BR' no mapeamento; filtros dinamicos so mostram valores que existem |
| `client` pode ser `null` no response (loja sem client vinculado) | Baixa | Baixo | Optional chaining + fallback string vazia no mapeamento |
| Grid vazia apos aplicar filtros confunde usuario | Media | Medio | Mensagem explicita "Nenhuma loja encontrada para os filtros selecionados" (AC 20.14.3) |
| Valores de `country`/`language` nao padronizados no banco (ex: `OTHER`, `en` sem regiao) | Media | Baixo | Adicionar mapeamento de display labels nos dropdowns (ex: `OTHER` -> `Outro`, `en` -> `English`) para UX mais polida |
