# Story 31.3 - Admin/Performance: Simplificar Union Manual com unified_invoices

## Epic
Epic 31 - Unified Invoices: Portal Visibility for All Charges

## Contexto
Varios endpoints admin e portal ja fazem queries paralelas em `invoices` + `client_charges` e somam os resultados manualmente no codigo. Com a VIEW `unified_invoices`, esses endpoints podem ser simplificados para uma unica query.
