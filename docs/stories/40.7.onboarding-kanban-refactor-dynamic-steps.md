# Story 40.7 — Onboarding Kanban Refactor: Dynamic Steps

## Story

**Como** coordenador/manager,
**Quero** que o kanban de onboarding mostre colunas baseadas no status dos steps (waiting, pending, in_progress, review, completed) em vez de fases fixas (pending_approval, generating_copies, design, implementation),
**Para que** eu veja o progresso real de cada etapa e possa interagir diretamente com os steps.

## Contexto

O kanban atual em `onboarding-kanban.tsx` usa fases fixas como colunas (`pending_approval`, `generating_copies`, `design`, `implementation`, `completed`). Com o novo modelo de steps dinamicos, as colunas devem refletir o lifecycle dos steps:

- **Aguardando** (`waiting`) — steps com dependencias nao satisfeitas
- **Pronto** (`pending`) — steps prontos para iniciar (deps met, actionable)
- **Em Andamento** (`in_progress`) — steps sendo trabalhados
- **Em Revisao** (`review`) — steps aguardando revisao
- **Concluido** (`completed`) — steps finalizados

Cada card no kanban e um `client_onboarding_step`, renderizado com o `OnboardingStepCard` compartilhado.

## Technical Notes

### Estrutura de dados para o kanban

```typescript
interface KanbanColumn {
  id: OnboardingStepStatus
  title: string
  icon: LucideIcon
  steps: StepWithRelations[]
}

interface StepWithRelations {
  id: string
  name: string
  description?: string
  category: string
  status: OnboardingStepStatus
  position: number
  assigned_to?: string
  depends_on_step_ids: string[]
  due_date?: string
  completed_at?: string
  task_id?: string
  onboarding: {
    id: string
    client: { id: string; name: string; company?: string }
    store?: { id: string; store_name: string }
  }
  assignee?: { id: string; name: string; avatar_url?: string; role: string }
  blocked_by_names?: string[]
}
```

### Fetch de dados

```typescript
// Buscar todos os steps com relacoes
const { data: steps } = await supabase
  .from("client_onboarding_steps")
  .select(`
    *,
    onboarding:client_onboardings(
      id,
      client:clients(id, name, company),
      store:client_stores(id, store_name)
    ),
    assignee:org_members(
      id,
      role,
      profile:profiles(name, avatar_url)
    )
  `)
  .in("status", ["waiting", "pending", "in_progress", "review", "completed"])
  .order("position", { ascending: true })
```

### Restricoes de drag-and-drop

```typescript
const VALID_DRAG_TRANSITIONS: Record<string, string[]> = {
  waiting: [],                      // Nao pode arrastar waiting (depende do DAG)
  pending: ["in_progress"],         // Iniciar trabalho ("ready to start")
  in_progress: ["review", "blocked", "completed"],
  review: ["completed", "in_progress"],
  blocked: ["pending", "in_progress"],
  completed: [],                    // Nao pode des-completar via drag
}
```
