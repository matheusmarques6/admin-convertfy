## Contexto

O componente `TotalRevenueBanner` (`src/components/dashboard/total-revenue-banner.tsx`) usa o padrao `useState + useEffect + fetch` para carregar dados de revenue. Outros componentes do projeto, como `useStorePerformance`, ja usam SWR (`swr@^2.4.0`) para data fetching, que oferece:

- Cache automatico e revalidacao
- Deduplicacao de requests (multiplas instancias do mesmo hook nao disparam requests duplicados)
- Estados de `isLoading`, `isValidating`, `error` nativos
- Revalidacao em foco (quando o usuario volta para a tab)
- Retry automatico em erro

Padronizar o `TotalRevenueBanner` com SWR alinha com o padrao existente e melhora a UX.

---

## Objetivo

Substituir `useState/useEffect/fetch` por `useSWR` no `TotalRevenueBanner`, mantendo o mesmo comportamento funcional.

## Arquitetura Tecnica

### Antes

```typescript
const [data, setData] = useState<TotalRevenueResponse | null>(null)
const [loading, setLoading] = useState(true)
const [error, setError] = useState<string | null>(null)

useEffect(() => {
  const fetchRevenue = async () => {
    setLoading(true)
    try {
      const res = await fetch(`/api/dashboard/total-revenue?period=${period}`)
      const json = await res.json()
      setData(json)
    } catch (err) {
      setError("Erro ao carregar revenue")
    } finally {
      setLoading(false)
    }
  }
  fetchRevenue()
}, [period])
```

### Depois

```typescript
import useSWR from "swr"

const fetcher = (url: string) => fetch(url).then(res => {
  if (!res.ok) throw new Error("Erro ao carregar revenue")
  return res.json()
})

const { data, error, isLoading } = useSWR<TotalRevenueResponse>(
  `/api/dashboard/total-revenue?period=${period}`,
  fetcher,
  {
    revalidateOnFocus: false,
    dedupingInterval: 60000,
  }
)
```
