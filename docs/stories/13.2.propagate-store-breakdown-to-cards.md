# Story 13.2 - Propagar storeBreakdown para os Cards

**Prioridade:** P2 (Enhancement)
**Sprint:** Current
**Assignee:** @dev
**Revisao:** @sm (River)
**Status:** Ready for Review
**Epic:** 13 - Ver Todas as Lojas (Modal com Paginacao)
**Fase:** 1 - Data Flow

---

## Contexto

A API `GET /api/dashboard/total-revenue` ja retorna o campo `storeBreakdown` (array com TODAS as lojas e suas receitas). Porem, a interface `TotalRevenueData` no frontend (em `total-revenue-banner.tsx`) nao inclui esse campo. Consequentemente, o `dashboard-layout.tsx` so passa `topStores` (top 5) e `bottomStores` (bottom 5) para os cards.

Para que os cards possam exibir o botao "Ver todas" com o modal completo, precisamos:
1. Adicionar `storeBreakdown` na interface `TotalRevenueData`
2. Passar `storeBreakdown` como prop `allStores` para ambos os cards
3. Adicionar a prop `allStores` nas interfaces dos cards

---

## Objetivo

Ajustar o data flow para que `storeBreakdown` (todas as lojas) chegue ate os cards `TopStoresCard` e `WorstPerformersCard`, sem alterar o comportamento visual atual. A story 13.3 usara essa prop para adicionar o botao.

## Arquitetura Tecnica

### Data Flow (atual vs novo)

```
ATUAL:
API (storeBreakdown) → SWR → TotalRevenueData (sem storeBreakdown)
                              → onDataChange → dashboard-layout
                                → topStores (5) → TopStoresCard
                                → bottomStores (5) → WorstPerformersCard

NOVO:
API (storeBreakdown) → SWR → TotalRevenueData (COM storeBreakdown)
                              → onDataChange → dashboard-layout
                                → topStores (5) + allStores (todas) → TopStoresCard
                                → bottomStores (5) + allStores (todas) → WorstPerformersCard
```

### Nota sobre sorting do `allStores`

O `storeBreakdown` retornado pela API NAO vem ordenado. O `buildResponse()` no backend ordena apenas para extrair top/bottom 5. Para o modal, a ordenacao sera feita no componente `StoresListModal` (story 13.1) ou no card (story 13.3), dependendo da variant:
- "top": `storeBreakdown` sorted descending por `totalRevenueBRL`
- "bottom": `storeBreakdown` sorted ascending por `totalRevenueBRL` (filtrando `totalRevenueBRL > 0`)
