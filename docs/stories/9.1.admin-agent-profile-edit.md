## Contexto

A pagina de perfil do admin (`src/app/(dashboard)/settings/profile/page.tsx`) eh um server component que nao permite edicao. Nao existe endpoint de API para leitura ou atualizacao do perfil do usuario logado. O portal do cliente possui uma implementacao funcional em `src/app/portal/settings/page.tsx` e `src/app/api/portal/settings/route.ts` que deve servir como referencia (~80% reutilizavel).

A policy de RLS ja existe: `"Users can update own profile" ON profiles FOR UPDATE USING (auth.uid() = id)`.

---

## Objetivo

1. Criar endpoints de API para leitura e atualizacao do perfil do usuario admin/agent
2. Converter a pagina de perfil de server component para client component com formulario editavel
3. Garantir que email e role nao possam ser atualizados via API

## Arquitetura Tecnica

### Endpoint GET /api/settings/profile

```typescript
// src/app/api/settings/profile/route.ts
import { createClient } from "@/lib/supabase/server";
import { NextResponse } from "next/server";

export async function GET() {
  const supabase = await createClient();
  const { data: { user }, error: authError } = await supabase.auth.getUser();

  if (authError || !user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  // Buscar profile
  const { data: profile, error: profileError } = await supabase
    .from("profiles")
    .select("id, name, email, avatar_url, phone")
    .eq("id", user.id)
    .single();

  // Buscar role via org_members
  const { data: membership } = await supabase
    .from("org_members")
    .select("role")
    .eq("user_id", user.id)
    .single();

  return NextResponse.json({
    ...profile,
    role: membership?.role ?? "unknown",
  });
}
```

### Endpoint PUT /api/settings/profile

```typescript
// src/app/api/settings/profile/route.ts
import { z } from "zod";

const profileUpdateSchema = z.object({
  name: z.string().min(2, "Nome deve ter pelo menos 2 caracteres").max(100).optional(),
  phone: z.string().max(20).optional().nullable(),
});

export async function PUT(request: Request) {
  const supabase = await createClient();
  const { data: { user }, error: authError } = await supabase.auth.getUser();

  if (authError || !user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const body = await request.json();
  const parsed = profileUpdateSchema.safeParse(body);

  if (!parsed.success) {
    return NextResponse.json(
      { error: "Validation failed", details: parsed.error.flatten() },
      { status: 400 }
    );
  }

  // WHITELIST: apenas name e phone
  const updateData: Record<string, unknown> = {};
  if (parsed.data.name !== undefined) updateData.name = parsed.data.name;
  if (parsed.data.phone !== undefined) updateData.phone = parsed.data.phone;

  const { error: updateError } = await supabase
    .from("profiles")
    .update(updateData)
    .eq("id", user.id);

  if (updateError) {
    return NextResponse.json({ error: "Failed to update profile" }, { status: 500 });
  }

  return NextResponse.json({ success: true });
}
```
