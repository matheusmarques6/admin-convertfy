**As a** desenvolvedor,

**so that** evitemos erros de tipo e garantamos validacao consistente em todo o projeto.

4. Tipo de retorno de `getStoreCredentials()` em `credentials.service.ts` atualizado para `client_id: string | null`
5. Nenhum erro de TypeScript no build (`npm run typecheck` passa com 0 erros)
6. Nenhum erro de lint (`npm run lint` passa)
7. Schemas existentes em `common.ts` NAO sao modificados
