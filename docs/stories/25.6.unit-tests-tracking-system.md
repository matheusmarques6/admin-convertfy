## Story

**Como** equipe que mantem um sistema de tracking publico sem nenhum teste automatizado,
**Quero** cobertura unitaria para as funcoes criticas (carrier detection, status mapping, sanitizacao),
**Para que** refactorings e fixes nao introduzam regressoes silenciosas.

---

## Contexto

O sistema de tracking tem **zero testes**. Nenhum `.test.ts` ou `.spec.ts` existe para:
- `src/lib/tracking/carriers.ts`
- `src/lib/services/tracking.service.ts`
- `src/app/api/tracking/lookup/route.ts`
- `src/lib/rate-limit.ts`

Isso significa que os fixes das stories 25.1-25.5 nao tem protecao contra regressao.

## Acceptance Criteria

### 25.6.1 — Testes para sanitizacao (protege fix 25.1)

- [ ] Testar `sanitizePostgrestValue()`:
  - Input normal: `"1001"` → `"1001"`
  - Injection: `",customer_email.neq.null"` → `"customeremailneqnull"` (ou vazio)
  - Parenteses: `"1001),id.gt.0"` → `"1001idgt0"`
  - Caracteres validos: `"order-123 #test"` → `"order-123 #test"`
- [ ] Testar `escapePostgrestLike()`:
  - `"AB%BR"` → `"AB\\%BR"`
  - `"test_value"` → `"test\\_value"`
  - `"normal"` → `"normal"`

### 25.6.2 — Testes para carrier detection

- [ ] Testar `detectCarrierProvider()` com:
  - `"AB123456789BR"` → correios
  - `"AB123456789CN"` → chinapost/cainiao
  - `"3STEST12345678901"` → postnl
  - `"LP123456789012345"` → cainiao
  - `"12345678901234"` (14 digitos) → jadlog
  - `"RANDOMCODE123"` → unknown

### 25.6.3 — Testes para status mapping

- [ ] Testar `inferCorreiosStatus()`:
  - `"Objeto entregue ao destinatario"` → `"delivered"`
  - `"Saiu para entrega"` → `"out_for_delivery"`
  - `"Objeto em transito"` → `"in_transit"`
  - `"Tentativa de entrega nao realizada"` → `"failed_attempt"`
  - `"Objeto devolvido"` → `"exception"`
- [ ] Testar `mapTrackingMoreStatus()`:
  - `"delivered"` → `"delivered"`
  - `"transit"` → `"in_transit"`
  - `"notfound"` → `"pending"`
  - `undefined` → `"pending"`
- [ ] Testar `mapSeventeenTrackStatus()`:
  - `{ track_info: { latest_status: { status: "Delivered" } } }` → `"delivered"`
  - `{ tag: "InTransit" }` → `"in_transit"`
  - `{ tag: "" }` → `"pending"`

### 25.6.4 — Testes para cache TTL

- [ ] Testar `getCacheTtl()`:
  - Mix de statuses: usa o menor TTL
  - Array vazio: retorna 60
  - Todos delivered: retorna 3600

### 25.6.5 — Testes para freshness guard

- [ ] Testar `isWithinFreshness()`:
  - `lastCheckedAt` = agora - 1min, status = `"in_transit"` (threshold 4h) → `true`
  - `lastCheckedAt` = agora - 5h, status = `"in_transit"` → `false`
  - `lastCheckedAt` = null → `false`
  - `hasEvents` = false, status = `"pending"` → threshold = 30min
