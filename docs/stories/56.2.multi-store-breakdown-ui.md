## Contexto

O protótipo aprovado está em `prototype-multi-store.html`. A visão geral do cliente já agrega dados de múltiplas lojas, mas não mostra DE ONDE veio cada parte. O objetivo é adicionar breakdown discreto por loja nos KPI cards e badges coloridos nas tabelas.

## Referência Visual

Abrir `prototype-multi-store.html` no navegador para referência exata.
**IMPORTANTE:** O protótipo usa nomes de cards diferentes da UI atual. Manter os nomes da UI atual (ver AC 56.2.3).

## Acceptance Criteria

### AC 56.2.1 — Store Color System

- [ ] Criar constante `STORE_COLORS` em `src/lib/constants/store-colors.ts` (reutilizável)
- [ ] Paleta de 6 cores muted para dark mode:
  - emerald-300 (`#6ee7b7`), blue-300 (`#93c5fd`), rose-300 (`#fda4af`), amber-300 (`#fcd34d`), violet-300 (`#c4b5fd`), cyan-300 (`#67e8f9`)
- [ ] Cada cor tem: `dot` (cor do ponto), `bg` (fundo translúcido `rgba(cor, 0.08)`), `text` (cor do texto)
- [ ] Função `getStoreColor(index: number)` com **fallback modular**: `STORE_COLORS[index % STORE_COLORS.length]`
- [ ] Cores atribuídas por ordem do `storeBreakdown` (maior revenue = primeira cor)
- [ ] **ATENÇÃO:** emerald-300 é próximo do verde do badge "Live". Garantir que o dot do badge "Live" mantenha a animação pulsante para diferenciação.
- [ ] Exportar `STORE_COLORS`, `getStoreColor`, e tipo `StoreColor`

### AC 56.2.2 — Store Legend

- [ ] Renderizar quando `storeBreakdown.length > 1` (NÃO `data.stores.length > 1`)
- [ ] Cada loja: dot colorido (7px, rounded-full) + nome da loja em `text-muted-foreground text-xs`
- [ ] Layout: `flex gap-4 flex-wrap`
- [ ] Posição: entre o header "Performance Convertfy" e os KPI cards
- [ ] Quando `storeBreakdown.length <= 1`, NÃO mostrar a legenda

### AC 56.2.3 — KPI Cards com Breakdown Expansível

- [ ] Os 4 cards da UI atual são (NÃO renomear — manter exatamente):
  1. **Receita Total** — valor `storeRevenue`, breakdown por `storeBreakdown[].storeRevenue`
  2. **Revenue Email** — valor `attributedRevenue`, breakdown por `storeBreakdown[].attributedRevenue`
  3. **Campanhas & Flows** — valor `totalCampaigns + totalFlows`, breakdown por `storeBreakdown[].sentCampaigns + liveFlows`
  4. **Recuperação Email** — valor `recoveryRate`, breakdown por `storeBreakdown[].recoveryRate`

- [ ] Cada card ganha (quando `storeBreakdown.length > 1`):
  1. **Proportion bar** (3px) abaixo do valor principal — segmentos coloridos proporcionais ao valor
  2. **Chevron** no header (ChevronDown, `text-muted-foreground` — NÃO `text-dim`, contraste suficiente)
  3. **Breakdown colapsável** (click to expand):
     - Divider `border-t border-border/50`
     - Uma linha por loja: dot + nome (truncate) + valor alinhado à direita
     - Transição suave (Tailwind: `overflow-hidden transition-all duration-300`)

- [ ] **EXCEÇÃO — Card "Recuperação Email":**
  - NÃO mostrar proportion bar (percentagens não são aditivas)
  - Mostrar APENAS o breakdown textual (cada loja com seu %)
  - Chevron e expand/collapse funcionam normalmente

- [ ] **Card "Receita Total" — breakdown inclui pedidos:**
  - Cada loja mostra: `R$ XX.XXX,XX` + `(XXX pedidos)` em text-muted

- [ ] Estado: `useState<Set<string>>` com keys: `'revenue'`, `'email'`, `'campaigns'`, `'recovery'`
- [ ] Quando `storeBreakdown.length <= 1`, NÃO mostrar proportion bar, chevron ou breakdown
- [ ] **Guard clause:** Se total do proportion bar é 0 (todas as lojas com valor 0), não renderizar a proportion bar

### AC 56.2.4 — Store Badges Coloridos nas Tabelas

- [ ] Substituir o `<Badge variant="outline">` por badge colorido com dot
- [ ] Estrutura: `<span>` com dot (5px) + nome, fundo translúcido na cor da loja
- [ ] Classes: `inline-flex items-center gap-1.5 text-[11px] font-medium px-2 py-0.5 rounded`
- [ ] Cor do fundo e texto matching o `storeColorMap` (mesmo Map usado nos KPI cards)
- [ ] Nome: completo com `max-w-[120px] truncate` para nomes longos
- [ ] Aplicar em AMBAS as tabelas: campanhas e flows
- [ ] Coluna "Loja" condicional: `storeBreakdown.length > 1` (alinhado com legend)

### AC 56.2.5 — Mini Revenue Bar nas Tabelas

- [ ] Na coluna "Pedido Realizado" (revenue), mini bar abaixo do valor
- [ ] Bar: `w-12 h-[3px] bg-muted/30 rounded-sm overflow-hidden`, fill na cor da loja
- [ ] Fill proporcional ao max revenue da tabela (maior item = 100%)
- [ ] **Guard clause:** Se `maxRevenue === 0`, não renderizar a mini bar
- [ ] Só mostrar quando `storeBreakdown.length > 1`

### AC 56.2.6 — Responsividade

- [ ] Store legend: `flex-wrap` (já no layout)
- [ ] KPI breakdown: nomes de loja com `truncate max-w-[140px]`
- [ ] Tabelas: overflow-x-auto mantido (já existente)
- [ ] Breakpoint KPI grid: `grid-cols-1 md:grid-cols-2 lg:grid-cols-4` (já existente)

### AC 56.2.7 — Dark Mode

- [ ] Proportion bar background: `bg-muted/20`
- [ ] Badge backgrounds: usar `bg` do `StoreColor` (já `rgba(cor, 0.08)`)
- [ ] Breakdown divider: `border-border/50`
- [ ] Funciona em dark (padrão) e light mode
