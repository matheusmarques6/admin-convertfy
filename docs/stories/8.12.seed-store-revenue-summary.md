## Contexto

Apos a aplicacao das migrations (Story 8.11), a tabela `store_revenue_summary` existe mas esta vazia. O dashboard le exclusivamente desta tabela via `/api/dashboard/total-revenue` (arquivo `src/app/api/dashboard/total-revenue/route.ts`). Sem dados na tabela, o dashboard retorna `storesCount: 0` e os componentes mostram o empty state "Conecte lojas".

Porem, os dados de revenue JA EXISTEM nas tabelas `klaviyo_flow_metrics` e `klaviyo_campaign_metrics` — foram populados pelo cron antigo. Precisamos de um script SQL one-time que agrega esses dados e popula o `store_revenue_summary` imediatamente, eliminando o problema de cold-start.

### Tabelas Fonte (ja possuem dados)

- `klaviyo_flow_metrics`: `store_id`, `conversion_value`, `period_start`, `period_end`, `fetched_at`
- `klaviyo_campaign_metrics`: `store_id`, `conversion_value`, `period_start`, `period_end`, `fetched_at`
- `client_stores`: `id`, `org_id`, `store_name`

### Tabela Destino

- `store_revenue_summary`: schema completo em `supabase/migrations/20260228_store_revenue_summary.sql`
  - Chave primaria: `(store_id, period_label)`
  - `org_id NOT NULL` — constraint obrigatorio
  - `sync_status` deve ser `'ok'` para dados validos
  - `expires_at` deve ser `NOW() + INTERVAL '6 hours'` para que o cron normal assuma depois

---

## Objetivo

Criar um script SQL one-time que popula `store_revenue_summary` a partir dos dados existentes em `klaviyo_flow_metrics` e `klaviyo_campaign_metrics`, para o periodo `30d` (mais utilizado no dashboard).

## Arquitetura Tecnica

### Estrutura do Seed SQL

```sql
-- seed_revenue_summary.sql
-- One-time seed: popula store_revenue_summary com dados existentes
-- Idempotente (UPSERT) — seguro para rodar multiplas vezes

WITH flow_totals AS (
  SELECT
    fm.store_id,
    SUM(fm.conversion_value) AS flow_revenue
  FROM klaviyo_flow_metrics fm
  WHERE fm.period_start >= (NOW() - INTERVAL '35 days')::date::text
    AND fm.period_end <= NOW()::date::text
  GROUP BY fm.store_id
),
campaign_totals AS (
  SELECT
    cm.store_id,
    SUM(cm.conversion_value) AS campaign_revenue
  FROM klaviyo_campaign_metrics cm
  WHERE cm.period_start >= (NOW() - INTERVAL '35 days')::date::text
    AND cm.period_end <= NOW()::date::text
  GROUP BY cm.store_id
),
combined AS (
  SELECT
    COALESCE(ft.store_id, ct.store_id) AS store_id,
    cs.org_id,
    COALESCE(ft.flow_revenue, 0) AS flow_revenue,
    COALESCE(ct.campaign_revenue, 0) AS campaign_revenue
  FROM flow_totals ft
  FULL OUTER JOIN campaign_totals ct ON ft.store_id = ct.store_id
  JOIN client_stores cs ON cs.id = COALESCE(ft.store_id, ct.store_id)
  WHERE cs.org_id IS NOT NULL
)
INSERT INTO store_revenue_summary (
  store_id, org_id, period_label,
  period_start, period_end,
  klaviyo_total_revenue, klaviyo_campaign_revenue, klaviyo_flow_revenue,
  shopify_total_revenue, sync_status, expires_at, fetched_at
)
SELECT
  store_id, org_id, '30d',
  NOW() - INTERVAL '30 days', NOW(),
  flow_revenue + campaign_revenue, campaign_revenue, flow_revenue,
  0, 'ok',
  NOW() + INTERVAL '6 hours', NOW()
FROM combined
ON CONFLICT (store_id, period_label) DO UPDATE SET
  klaviyo_total_revenue = EXCLUDED.klaviyo_total_revenue,
  klaviyo_campaign_revenue = EXCLUDED.klaviyo_campaign_revenue,
  klaviyo_flow_revenue = EXCLUDED.klaviyo_flow_revenue,
  sync_status = 'ok',
  expires_at = EXCLUDED.expires_at,
  fetched_at = EXCLUDED.fetched_at;
```

**NOTA:** O SQL acima e um guia. O dev deve ajustar os filtros de `period_start`/`period_end` conforme o formato real armazenado nas tabelas `klaviyo_flow_metrics` e `klaviyo_campaign_metrics` (sao strings `YYYY-MM-DD`, nao timestamps).

### Verificacao de Consistencia

Apos rodar o seed, comparar totais:

```sql
-- Total revenue no summary
SELECT SUM(klaviyo_total_revenue) FROM store_revenue_summary WHERE period_label = '30d';

-- Total revenue nas tabelas fonte (deve ser ~igual)
SELECT
  (SELECT COALESCE(SUM(conversion_value), 0) FROM klaviyo_flow_metrics
   WHERE period_start >= (NOW() - INTERVAL '35 days')::date::text) +
  (SELECT COALESCE(SUM(conversion_value), 0) FROM klaviyo_campaign_metrics
   WHERE period_start >= (NOW() - INTERVAL '35 days')::date::text)
AS source_total;
```

| Valores nao batem 100% com o dashboard antigo | Tolerancia de 1% aceita; diferencas podem existir por arredondamento ou filtros |
