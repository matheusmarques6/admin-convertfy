## Story

**Como** usuario do portal do cliente,
**Quero** que as paginas so facam fetch de dados apos o layout ter carregado o contexto (user, stores, activeStore),
**Para que** os dados carreguem corretamente ao abrir o portal ou dar refresh.

---

## Contexto

O portal tem um problema de **estado desacoplado via localStorage**:

O layout (`layout.tsx`) bloqueia rendering dos children enquanto `loading === true` (linhas 234-243),
o que previne uma race condition pura no carregamento inicial. Porem, o problema real e que
**cada pagina le `storeId` do localStorage independentemente** em vez de receber do layout:

```
Layout (carrega auth + stores + activeStore em state local)
  └→ setLoading(false) → renderiza children
       └→ Dashboard useEffect → le localStorage("portal_active_store") ← DESACOPLADO
            └→ fetch /api/portal/dashboard?store_id=X
```

**Problemas concretos:**
1. Layout determina `activeStore` (via stores API + localStorage), mas paginas filhas
   leem localStorage por conta propria — os dois podem divergir
2. Na **troca de store**, o layout faz `window.location.reload()` (linha 225), forcando
   um reload completo em vez de atualizar via state
3. Em **navegacoes subsequentes** (pagina → pagina), o `useEffect` do layout re-executa
   por causa da dependencia `[pathname]`, mas paginas nao esperam essa re-execucao
4. Se localStorage esta vazio/invalido, a pagina envia `store_id=null` e a API retorna
   dados vazios silenciosamente

---

## Solucao Proposta

Criar um **PortalContext** (React Context) no layout que:
1. Faz o auth check e carrega stores
2. Expoe `user`, `stores`, `activeStore`, `isReady` via context
3. Paginas filhas usam o context e so fazem fetch quando `isReady === true`

Alternativa: usar um state `isReady` no layout e nao renderizar `{children}` ate estar pronto
(o layout ja faz isso parcialmente com `if (loading) return <Spinner>`).

      `{ user, stores, activeStore, isReady, setActiveStore }`

      analytics, integrations, tracking, invoices, stores) consomem `activeStore` do context

      (sem window.location.reload)
- [ ] **CA5**: Refresh (F5) carrega dados corretamente sem flash de dados vazios
- [ ] **CA6**: Typecheck + lint passando
