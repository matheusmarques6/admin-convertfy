# Story 38.2 -- Remover referencia a `visual_reference_url` inexistente

## Story

Como desenvolvedor,
Quero remover a referencia ao campo `visual_reference_url` que nao existe na tabela `store_onboarding_data`,
Para que o payload enviado ao N8N nao contenha campos fantasma e o codigo reflita a realidade do banco.

## Contexto

### Problema observado

O phase service (`onboarding-phase.service.ts:183`) seleciona `visual_reference_url` da tabela `store_onboarding_data`, mas essa coluna **nao existe** em nenhuma migration. O Supabase/PostgREST silenciosamente retorna `null` para campos inexistentes no SELECT, entao nao ha crash, mas o dado nunca chega ao N8N.

### Codigo atual

```typescript
// onboarding-phase.service.ts:183
const { data: formData } = await adminClient
  .from("store_onboarding_data")
  .select("price_sensitivity, additional_notes, logo_url, design_direction_text, design_direction_file_url, brand_manual_url, visual_reference_url")
  .eq("store_id", onboarding.store_id)
  .maybeSingle()
```

E na linha 222:
```typescript
// onboarding-phase.service.ts:222
visual_reference_url: formData?.visual_reference_url,
```

### Colunas reais de `store_onboarding_data`

Conforme migration `20260220_store_onboarding_system.sql`:
- `price_sensitivity`, `additional_notes`, `logo_url`
- `design_direction_text`, `design_direction_file_url`, `brand_manual_url`
- `filled_by`, `filled_at`, `is_complete`
- **NAO existe:** `visual_reference_url`
