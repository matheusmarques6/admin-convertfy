# Story 42.13 — UI: Indicadores de RSVP do Google

## Story

**Como** admin user da plataforma,
**Quero** ver o status de RSVP do Google Calendar de cada participante,
**Para que** eu saiba quem confirmou a reuniao diretamente pelo Google Calendar.

## Contexto

### Estado atual

- `meeting_participants` tem `response_status` (RSVP local) e `google_rsvp_status` (do Google, story 42.1/42.11)
- `MeetingInviteActions` mostra botoes aceitar/recusar para o user logado
- Lista de participantes em meetings mostra apenas nome e status local
- Nao ha indicacao de quando foi o ultimo sync com Google

### O que precisa mudar

1. Lista de participantes mostra `google_rsvp_status` quando disponivel
2. Icons visuais para cada status
3. Indicacao quando local e Google divergem
4. Timestamp de ultimo sync

## Acceptance Criteria

- [x] **AC 42.13.1**: Lista de participantes em cada meeting mostra `google_rsvp_status` quando disponivel:
  - Coluna ou badge adicional "Google RSVP" ao lado do status local
  - Se `google_rsvp_status` e null: nao mostrar (participante pode nao estar no Google Calendar)

- [x] **AC 42.13.2**: Icons para cada status de RSVP Google:
  - `accepted`: check verde (CheckCircle)
  - `declined`: X vermelho (XCircle)
  - `tentative`: interrogacao amarelo (HelpCircle)
  - `pending` (needsAction): relogio cinza (Clock)

- [x] **AC 42.13.3**: Se RSVP local difere do Google, mostrar ambos com indicacao visual:
  - Exemplo: status local "Pendente" + badge Google "Aceito" — destacar divergencia
  - Tooltip: "RSVP local: Pendente | Google Calendar: Aceito"
  - Cor diferenciada (borda amarela) para chamar atencao

- [x] **AC 42.13.4**: Timestamp de ultimo sync visivel:
  - Texto: "Ultimo sync: ha 15 minutos" (formatado relativamente)
  - Usa `user_google_tokens.last_synced_at` do organizador
  - Botao "Sincronizar agora" ao lado (chama endpoint manual da 42.11)

## Technical Notes

### Componente sugerido

```tsx
function ParticipantRsvpStatus({
  localStatus,
  googleStatus,
}: {
  localStatus: string
  googleStatus?: string | null
}) {
  const icons = {
    accepted: { icon: CheckCircle, color: 'text-green-500', label: 'Aceito' },
    declined: { icon: XCircle, color: 'text-red-500', label: 'Recusado' },
    tentative: { icon: HelpCircle, color: 'text-yellow-500', label: 'Talvez' },
    pending: { icon: Clock, color: 'text-muted-foreground', label: 'Pendente' },
  }

  const isDivergent = googleStatus && googleStatus !== localStatus

  return (
    <div className="flex items-center gap-2">
      <Badge variant={isDivergent ? 'outline' : 'default'}>
        {icons[localStatus]?.label || localStatus}
      </Badge>
      {googleStatus && isDivergent && (
        <Tooltip content={`Google Calendar: ${icons[googleStatus]?.label}`}>
          <Badge variant="secondary" className="gap-1">
            <icons[googleStatus].icon className={cn('h-3 w-3', icons[googleStatus].color)} />
          </Badge>
        </Tooltip>
      )}
    </div>
  )
}
```

### Dados necessarios

Queries de meetings precisam retornar `google_rsvp_status` dos participantes e `last_synced_at` do organizador.
