# Story 5.3 - Melhorar Vinculo Loja-Cliente: Alerta e Contexto Automatico

**Prioridade:** Media

**Assignee:** @dev
**Revisao:** @sm (River)
**Status:** Ready for Review

## Contexto

O `QuickStoreForm` (`src/components/stores/quick-store-form.tsx`) permite criar lojas com `client_id = null`. Quando o usuario nao seleciona um cliente, a loja fica "avulsa" — sem vinculo a nenhum cliente.

Embora a Story 5.1 corrija o impacto no dashboard (lojas avulsas excluidas do calculo), o problema de UX persiste: nao ha **alerta visivel** de que a loja nao esta vinculada, e o mecanismo de vinculacao (`StoreLinkActions`/`StoreLinkModal`) existe mas eh uma acao manual pouco descoberta.

Alem disso, quando o usuario cria uma loja **a partir da pagina de um cliente** (ex: `/clients/[id]`), o `client_id` deveria ser preenchido automaticamente, mas isso nao acontece.

---

## Objetivo

1. Auto-preencher `client_id` quando a loja eh criada no contexto de um cliente
2. Adicionar alerta visivel para lojas sem cliente vinculado
3. Manter a possibilidade de criar lojas avulsas (nao tornar `client_id` obrigatorio)

---

## Arquitetura Tecnica

### QuickStoreForm — Nova Prop

```typescript
// ANTES:
interface QuickStoreFormProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  onSuccess?: (store: any) => void
}

// DEPOIS:
interface QuickStoreFormProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  onSuccess?: (store: any) => void
  defaultClientId?: string  // Pre-seleciona cliente ao abrir
}
```

No `useEffect` ou inicializacao do form:
```typescript
useEffect(() => {
  if (defaultClientId && open) {
    // Buscar dados do cliente para exibir no campo
    fetchClient(defaultClientId).then(client => {
      if (client) {
        setSelectedClient(client)
        setValue("client_id", client.id)
      }
    })
  }
}, [defaultClientId, open])
```

### Badge de Alerta na Listagem

Verificar o componente que renderiza cada loja na listagem (`/stores`). Adicionar condicional:

```tsx
{!store.client_id && (
  <Badge
    variant="outline"
    className="border-yellow-500/50 text-yellow-600 dark:text-yellow-400 cursor-pointer"
    onClick={() => openLinkModal(store.id)}
  >
    <AlertTriangle className="h-3 w-3 mr-1" />
    Sem cliente
  </Badge>
)}
```

### Banner na Pagina de Detalhe

```tsx
{!store.client_id && (
  <Alert variant="warning" className="mb-4">
    <AlertTriangle className="h-4 w-4" />
    <AlertTitle>Loja sem cliente vinculado</AlertTitle>
    <AlertDescription>
      Esta loja nao esta vinculada a nenhum cliente.
      Vincular a um cliente permite melhor organizacao e relatorios.
      <Button variant="link" onClick={() => setShowLinkModal(true)}>
        Vincular agora
      </Button>
    </AlertDescription>
  </Alert>
)}
```
