## Contexto

A tabela `dashboard_cache` nao possui coluna `org_id`. A RLS policy atual (`Users can view dashboard_cache`) usa `is_org_member()`, o que significa que **qualquer membro de qualquer org pode ler qualquer cache entry**. Isso eh uma vulnerabilidade de isolamento cross-tenant.

A tabela eh usada pela lib `src/lib/cache.ts` para funcoes `getCache()`, `setCache()`, `getStaleCache()`, `cleanExpiredCache()` e `invalidateCache()`. Nenhuma dessas funcoes filtra por `org_id`.

---

## Objetivo

1. Adicionar coluna `org_id NOT NULL` na tabela `dashboard_cache`
2. Backfill valores existentes via `client_stores.org_id`
3. Corrigir RLS policy para filtrar por `org_id = current_org_id()`
4. Atualizar `src/lib/cache.ts` para incluir `org_id` nas operacoes de leitura e escrita

## Arquitetura Tecnica

### Migration SQL

```sql
-- Arquivo: supabase/migrations/YYYYMMDD_dashboard_cache_org_id.sql

-- 1. Adicionar coluna org_id
ALTER TABLE dashboard_cache
  ADD COLUMN IF NOT EXISTS org_id UUID REFERENCES organizations(id);

-- 2. Backfill via client_stores
UPDATE dashboard_cache dc
SET org_id = cs.org_id
FROM client_stores cs
WHERE dc.store_id = cs.id
  AND cs.org_id IS NOT NULL
  AND dc.org_id IS NULL;

-- 3. Indice para queries filtradas por org
CREATE INDEX IF NOT EXISTS idx_dashboard_cache_org
  ON dashboard_cache(org_id, cache_type, period);

-- 4. Corrigir RLS policy
DROP POLICY IF EXISTS "Users can view dashboard_cache" ON dashboard_cache;
CREATE POLICY "org_dashboard_cache_select" ON dashboard_cache
  FOR SELECT TO authenticated
  USING (
    org_id = current_org_id()
    OR can_access_store(store_id)
  );
```

**Nota:** A coluna eh adicionada como nullable para permitir backfill gradual. Entries antigas sem `store_id` valido podem ficar com `org_id = NULL` — serao limpas pelo `cleanExpiredCache`.

### Alteracoes em `src/lib/cache.ts`

#### setCache - adicionar orgId

```typescript
export async function setCache(
  supabase: SupabaseClient,
  storeId: string,
  cacheType: string,
  period: string,
  data: Record<string, unknown>,
  orgId?: string
): Promise<void> {
  const ttlMinutes = getTTLMinutes(cacheType, period)
  const expiresAt = new Date(Date.now() + ttlMinutes * 60 * 1000).toISOString()

  try {
    await supabase.from("dashboard_cache").upsert(
      {
        store_id: storeId,
        cache_type: cacheType,
        period,
        data: { ...data, _cacheVersion: CACHE_VERSION },
        created_at: new Date().toISOString(),
        expires_at: expiresAt,
        ...(orgId && { org_id: orgId }),
      },
      { onConflict: "store_id,cache_type,period" }
    )
  } catch (error) {
    log.warn(`[Cache SET FAILED] ${cacheType}/${period}:`, error)
  }
}
```
