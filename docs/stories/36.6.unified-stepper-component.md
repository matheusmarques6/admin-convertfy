# Story 36.6 — Stepper Unificado (Componente Compartilhado)

## Contexto

Os dois formularios usam steppers visuais completamente diferentes:
- **Form publico**: Botoes pill com icones + label, clicaveis quando completos, `hidden sm:inline` para labels
- **Wizard portal**: Circles 40px com linhas conectoras, NAO clicaveis, sem labels no stepper

Visualmente parecem de projetos diferentes. Ambos tem problemas de responsividade em telas <375px.

## Objetivo

Criar um unico componente `<OnboardingStepper>` usado em ambos os formularios, com:
- Circles com icones + linhas conectoras (visual mais limpo)
- Labels visiveis em desktop, "Passo X de N" em mobile
- Clicavel em steps completos
- Roles ARIA corretos

## Criterios de Aceitacao

- [x] **AC 36.6.1**: Criar `src/components/onboarding/stepper.tsx` com componente `OnboardingStepper`
- [x] **AC 36.6.2**: Props: `steps: { id: string, label: string, icon: LucideIcon }[]`, `currentIndex: number`, `onNavigate: (index: number) => void`
- [x] **AC 36.6.3**: Visual: circles com icone (ativo = primary, completo = emerald, futuro = muted) + linhas conectoras
- [x] **AC 36.6.4**: Em desktop (>=640px): label visivel abaixo de cada circle
- [x] **AC 36.6.5**: Em mobile (<640px): labels ocultos, mostrar "Passo X de N — {label}" como texto centralizado abaixo
- [x] **AC 36.6.6**: Click em step completo chama `onNavigate(index)`. Steps futuros nao sao clicaveis
- [x] **AC 36.6.7**: Acessibilidade: `<nav aria-label="Progresso do formulario">`, `aria-current="step"` no ativo, `aria-disabled="true"` nos futuros
- [x] **AC 36.6.8**: Form publico usa `<OnboardingStepper>` e remove JSX do stepper local
- [x] **AC 36.6.9**: Wizard portal usa `<OnboardingStepper>` e remove JSX do stepper local
