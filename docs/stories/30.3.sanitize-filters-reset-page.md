## Contexto
Problema no `clients-filters.tsx`:

**`clearFilter()` preserva `page` stale**: Ao limpar um filtro individual, o codigo faz `new URLSearchParams(searchParams)` e deleta apenas o filtro clicado, mas mantem o param `page`. Se o usuario estava na pagina 3 de resultados filtrados e remove o filtro, a pagina 3 pode nao existir nos resultados sem filtro — resultando em tabela vazia.

> **NOTA:** A validacao server-side (status/health contra enum, trim no search, sanitizar page) foi movida para a Story 30.1 (ACs 30.1.10-13). Esta story cobre APENAS os fixes client-side.

## Objetivo
Resetar `page` para 1 ao limpar filtros (individuais ou todos) e ao aplicar novos filtros.

---

## Acceptance Criteria

- [x] **30.3.1** `clearFilter()` remove o param `page` alem do filtro sendo limpo
- [x] **30.3.2** `applyFilters()` remove o param `page` ao aplicar novos filtros (volta para pagina 1)
- [x] **30.3.3** `applyFilters()` aplica `.trim()` no search antes de incluir na URL

## Arquitetura Tecnica

### Fix 1: clearFilter reset page (`clients-filters.tsx` linha 59-65)

#### ANTES
```typescript
function clearFilter(key: string) {
  if (key === "status") setStatus("all")
  if (key === "health") setHealth("all")
  const params = new URLSearchParams(searchParams)
  params.delete(key)
  router.push(`/clients?${params.toString()}`)
}
```

#### DEPOIS
```typescript
function clearFilter(key: string) {
  if (key === "status") setStatus("all")
  if (key === "health") setHealth("all")
  const params = new URLSearchParams(searchParams.toString())
  params.delete(key)
  params.delete("page") // Reset para pagina 1
  const qs = params.toString()
  router.push(qs ? `/clients?${qs}` : "/clients")
}
```

### Fix 2: applyFilters reset page (`clients-filters.tsx` linha 51-57)

#### ANTES
```typescript
function applyFilters() {
  const params = new URLSearchParams()
  if (search) params.set("search", search)
  if (status !== "all") params.set("status", status)
  if (health !== "all") params.set("health", health)
  router.push(`/clients?${params.toString()}`)
}
```

#### DEPOIS
```typescript
function applyFilters() {
  const params = new URLSearchParams()
  if (search.trim()) params.set("search", search.trim())
  if (status !== "all") params.set("status", status)
  if (health !== "all") params.set("health", health)
  // Nao inclui page — sempre volta para pagina 1
  const qs = params.toString()
  router.push(qs ? `/clients?${qs}` : "/clients")
}
```

> **NOTA:** Fix 3 (validacao server-side) foi movido para Story 30.1 (ACs 30.1.10-13).
