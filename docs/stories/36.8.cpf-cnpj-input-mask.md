# Story 36.8 — Mascara CPF/CNPJ com Deteccao Automatica

## Contexto

Ambos os formularios aceitam CPF/CNPJ como texto livre sem formatacao. O placeholder mostra `000.000.000-00` mas o campo aceita qualquer coisa. Nao ha validacao de formato.

## Objetivo

Criar componente `<CpfCnpjInput>` que formata automaticamente conforme o usuario digita:
- Ate 11 digitos → CPF: `000.000.000-00`
- Acima de 11 digitos → CNPJ: `00.000.000/0000-00`
