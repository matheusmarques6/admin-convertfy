# Story 40.8 — Realtime Updates for Steps + Tasks

## Story

**Como** membro da equipe olhando meu board,
**Quero** que novos cards de onboarding aparecam automaticamente sem precisar recarregar a pagina,
**Para que** eu veja em tempo real quando uma nova etapa esta pronta para mim.

## Contexto

O sistema ja usa Supabase Realtime para `client_onboardings` (migration `20260315_enable_realtime_client_onboardings.sql`). Precisamos estender para:

1. `client_onboarding_steps` — para que o kanban de onboarding atualize em tempo real
2. `tasks` — para que o board pessoal atualize quando novas tasks sao criadas pelo sync

O hook `useRealtimeOnboarding` ja existe e precisa ser expandido. O board pessoal precisa de um hook similar.

## Acceptance Criteria

- [x] **AC 40.8.1**: Tabela `client_onboarding_steps` adicionada ao Supabase Realtime (migration: `ALTER PUBLICATION supabase_realtime ADD TABLE client_onboarding_steps`)
- [x] **AC 40.8.2**: Hook `useRealtimeOnboarding` expandido para ouvir changes em `client_onboarding_steps` (INSERT, UPDATE)
- [x] **AC 40.8.3**: Quando um step muda de status, o kanban de onboarding move o card para a coluna correta sem refresh
- [x] **AC 40.8.4**: Quando uma nova task e criada (INSERT em `tasks`), o board pessoal adiciona o card automaticamente
- [x] **AC 40.8.5**: Quando uma task muda de status (UPDATE em `tasks`), o board move o card para a coluna correta
- [x] **AC 40.8.6**: Filtro de realtime: board pessoal so ouve changes para tasks do usuario logado (`assignee_id = current_user`)
- [x] **AC 40.8.7**: Toast notification quando novo card de onboarding aparece no board: "Nova tarefa: {step.name}"

### Hook para board

```typescript
// src/hooks/use-realtime-board.ts (novo ou expandir existente)

function useRealtimeBoard(userId: string) {
  const supabase = createClient()

  useEffect(() => {
    const channel = supabase
      .channel("board-tasks")
      .on(
        "postgres_changes",
        {
          event: "*",
          schema: "public",
          table: "tasks",
          filter: `assignee_id=eq.${userId}`,
        },
        (payload) => {
          if (payload.eventType === "INSERT") {
            // Adicionar card ao board
            addTask(payload.new)
            // Toast se for onboarding step
            if (payload.new.source_type === "auto_onboarding_step") {
              toast({ title: `Nova tarefa: ${payload.new.title}` })
            }
          } else if (payload.eventType === "UPDATE") {
            // Atualizar card existente
            updateTask(payload.new)
          }
        }
      )
      .subscribe()

    return () => { supabase.removeChannel(channel) }
  }, [userId])
}
```
