# Story 40.5 — Notification Chain on Step Ready

## Story

**Como** membro da equipe,
**Quero** ser notificado quando uma etapa de onboarding que depende de mim ficar pronta,
**Para que** eu saiba imediatamente que posso comecar a trabalhar nela.

## Contexto

Quando o DB trigger transiciona um step de `waiting` para `pending` (deps met), o membro atribuido a esse step precisa ser notificado. A notificacao deve:

1. Aparecer no sino de notificacoes in-app (via `notifications` table)
2. Incluir link direto para o onboarding ou para a task no board
3. Informar quem completou o step anterior (contexto)

O `NotificationService` ja existe e suporta criar notificacoes individuais e em bulk.

## Acceptance Criteria

- [x] **AC 40.5.1**: Quando um step transiciona para `pending`, uma notificacao e criada para o membro atribuido ao step
- [x] **AC 40.5.2**: Notificacao tem titulo: `Nova etapa de onboarding: {step.name}` e body: `{client.name} - {store.name}: etapa "{step.name}" esta pronta para iniciar`
- [x] **AC 40.5.3**: Notificacao inclui `link` para `/admin/board` (board pessoal onde a task aparecera)
- [x] **AC 40.5.4**: Notificacao inclui `metadata` com `{ onboarding_id, step_id, step_name }`
- [x] **AC 40.5.5**: Se o step nao tem assignee, nao criar notificacao (nao falhar)
- [x] **AC 40.5.6**: Notificacao e criada APOS a task do board ser criada (para que o membro ja veja a task ao clicar no link)
- [x] **AC 40.5.7**: Usar `notificationService.create()` com profile_id do membro (nao org_member_id — resolver via org_members.profile_id)

## Technical Notes

### Funcao de notificacao

```typescript
// Pode ser uma funcao helper dentro de onboarding-sync.service.ts
// ou um metodo estatico novo

async function notifyStepReady(params: {
  stepId: string
  stepName: string
  assignedToOrgMemberId: string
  onboardingId: string
  clientName: string
  storeName?: string
}): Promise<void> {
  const supabase = await createAdminClient()

  // Resolver profile_id do org_member
  const { data: member } = await supabase
    .from("org_members")
    .select("profile_id")
    .eq("id", params.assignedToOrgMemberId)
    .single()

  if (!member?.profile_id) return

  await notificationService.create({
    user_id: member.profile_id,
    title: `Nova etapa de onboarding: ${params.stepName}`,
    body: `${params.clientName}${params.storeName ? ` - ${params.storeName}` : ""}: etapa "${params.stepName}" esta pronta para iniciar`,
    type: "info",
    link: "/admin/board",
    metadata: {
      onboarding_id: params.onboardingId,
      step_id: params.stepId,
      step_name: params.stepName,
    },
  })
}
```

### Onde chamar

Dentro de `OnboardingSyncService.handleNewlyPendingSteps()` (story 40.4), apos criar a task no board:

```typescript
// Para cada step que ficou pending:
const taskId = await TaskAutomationService.onOnboardingStepPending(...)
if (taskId && step.assigned_to) {
  await notifyStepReady({
    stepId: step.id,
    stepName: step.name,
    assignedToOrgMemberId: step.assigned_to,
    onboardingId,
    clientName,
    storeName,
  })
}
```
