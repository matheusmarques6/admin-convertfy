# CRM Keyboard Shortcuts

## Global

- **Cmd/Ctrl + K** — abre command palette (busca de pages, ações,
  pipelines, leads, deals e clientes em tempo real).

## Navegacao rapida (somente em /admin/crm/*)

Sequencia de duas teclas estilo Linear/Superhuman: pressione **g** e
depois a segunda letra. A janela e de 1.5s.

| Atalho | Destino |
|--------|---------|
| `g l` | Leads |
| `g p` | Pipelines comerciais |
| `g c` | Customer Success (pipelines) |
| `g d` | Dashboard comercial |
| `g i` | Inbox |
| `g a` | Automacoes |
| `g r` | Reports CRM |

## Inbox

- **Cmd/Ctrl + Enter** — envia a mensagem em digitacao no composer.

## Builder de automacao (ReactFlow)

- Atalhos do ReactFlow padrao: arrastar nodes, conectar via handles,
  selecionar e Delete pra remover.

## Atalhos NAO ativos quando

- Foco esta em `<input>`, `<textarea>`, `<select>` ou elemento
  contenteditable.
- Modificadores Cmd/Ctrl/Alt estao pressionados (exceto pra Cmd+K).
