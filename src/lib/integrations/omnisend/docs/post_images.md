# post_images — POST /api/images

Upload an image from a **public URL** (HTTP/HTTPS). Returns an image `id` used by form `image` blocks, `backgroundImage`, email templates, push/MMS.

- **Required:** `url` · **Optional:** `name` (else derived from URL path)
- Formats: JPEG, PNG, GIF, WebP (detected from content). Max 5 MB. Wider than 2000px → auto-resized.
- Same URL already uploaded for the brand → returns the existing image.
- Private IPs blocked. The URL must resolve to a direct static asset (CDN/object storage) — redirect-backed or CMS-routed URLs are rejected.
- **Images generated by the ConvertIA (`convertia_gerar_imagem`)**: the tool result carries TWO URLs. The `URL` (under `/api/ai/convertia/imagem/…`) is for showing the image in the chat and is behind the admin login — the Omnisend cannot fetch it. Use the **`URL pública`** (under `/api/public/convertia-asset/…?sig=…`) here: it is a signed, static, no-login link made for platforms to download. Pass it verbatim, including the `sig` query string.

```json
{ "url": "https://cdn.shopify.com/s/files/1/0000/0000/products/banner.png", "name": "banner-roleta" }
```

Related: `get_images` (GET /api/images), `get_images_id`, `post_images_upload` (multipart file), `delete_images_id`.
